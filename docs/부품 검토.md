# 부품 검토: 패널 수신기에 필요한 것, 겹치는 것, 더 나은 것

> 2026-11-19 에 다시 썼다. 안테나 판을 사 오는 2.4 GHz 판(CoreHW CHW1010-ANT2)에서 직접 만드는 두 대역 판으로 바꿨다 ([작품 범위](작품%20범위.md), [스펙 008](../specs/008-dual-band-panel/spec.md)). 숙소에서 쓰는 회전 받침도 더했다.

## 한눈에

| 물음 | 답 |
|---|---|
| 지금 부품으로 할 일을 다 하나 | 계산으로는 한다. 실물에서 네 가지가 되어야 한다: ACK 의 CSI (관문 1), 세기로 위상 되찾기 (관문 2, 3), 두 대역 판의 방향 (관문 4), 패널 둘의 자리 (관문 5) |
| 겹치는 부품이 있나 | 탐지용 동글은 패널의 ESP32-C5 와 겹쳐 보이지만 빼지 않는다. 패널의 ESP32-C5 는 위치를 재는 동안 한 채널에 묶여 채널을 돌며 엿들을 수 없다 |
| 더 싼 구성이 있나 | 안테나를 4개로 줄이면 스위치가 다섯 줄어 패널마다 약 15만 원 싸고, 계산으로 옆자리까지 77~86% (16개는 81~93%) 다. 관문 3 다음에 4개로 먼저 재 보는 것은 권한다 |
| 더 나은 부품이 있나 | RF 모듈 일곱을 기판 하나로 줄이면 통이 얇아지고 위상 오차가 준다. 패널이 실물에서 된 뒤의 일이다 |
| 먼저 살 것 | ESP32-C5 두 개, 3만 원. 그다음은 통과할 때마다 7.9만 → 5.3만 → 26.2만 → 41.3만 원, 모두 약 84만 원 ([부품표](부품표.md#사는-순서-관문)) |

## 1. 부품마다 하는 일

| 부품 | 하는 일 | 없으면 |
|---|---|---|
| 필름 안테나 16 (Molex 146153) | 같은 전파를 16자리에서 받는다. 2.4 GHz 와 5 GHz 를 다 받는다 | 방향을 못 잰다 |
| 안테나 받침판 (뽑는다) + 반사판 | 안테나를 33 mm 간격, 45도로 잡고, 뒤쪽 전파를 막는다 | 간격이 틀어지면 방향이 틀어진다. 반사판이 없으면 앞뒤를 못 가른다 |
| HMC7992 다섯 (16갈래) | 첫 단 넷이 넷씩, 둘째 단이 그중 하나를 골라 안테나 하나를 내보낸다 | 안테나를 바꿔 가며 잴 수 없다 |
| 기준 안테나 (필름 안테나 하나) | 위상의 기준. 고른 안테나와 합쳐 세기를 잰다 | 패킷마다 위상 기준이 달라 안테나끼리 견줄 수 없다 |
| HMC7992 둘 + 길이가 다른 선 넷 | 기준 길의 위상을 네 단계로 바꾼다 | 위상의 부호를 모른다 (좌우가 뒤집힌 답이 함께 나온다) |
| 합침기 (2~6 GHz) | 기준과 고른 안테나를 더한다 | 세기에 위상이 담기지 않는다. 2.4 GHz 용은 5 GHz 에서 맞지 않는다 |
| U.FL 잭 - SMA 수 변환 단자, 짧은 SMA 선 | 필름 안테나(U.FL)와 모듈(SMA 암)을 잇는다 | 선이 끼워지지 않는다 |
| ESP32-C5 | 스위치를 돌리고, 빈 프레임을 보내고, 응답의 세기(CSI)를 잰다 | - |
| 허브 (파이 + 동글 둘 + 배터리) | 둘레를 엿들어 의심 기기를 고르고, 패널이 잰 것을 모아 자리를 내고, 폰에 보여 준다 | 탐지와 계산을 할 곳이 없다 |
| 회전 받침 (뽑는다 + 베어링 + 28BYJ-48) | 숙소에서 패널 하나를 20도 기울여 45도씩 돌린다 | 몰카 반대쪽을 보고 놓인 패널이 못 찾는다. 돌리면 숙소 오차가 0.28 → 0.20 m 로 준다 ([추정 구간 계산 5절](추정%20구간%20계산.md)) |

## 2. 겹치는 부품

- **라디오 넷.** 파이의 Wi-Fi, 동글 둘, 패널의 ESP32 둘. 동글 하나는 폰과의 통신에, 하나는 엿듣기에 쓴다. 패널의 ESP32 도 엿들을 수 있으므로 탐지용 동글과 일이 겹친다. 다만 사진만 가끔 보내는 카메라를 놓치지 않으려면 채널을 지키는 라디오가 많을수록 좋다. 그래서 빼지 않는다.
- **배터리.** 허브 가까이 거는 패널은 허브에서 USB 로 전원을 받는다. 먼 패널만 18650 을 쓴다.
- **걸이.** 자석 걸이판과 받침 발은 같은 구멍에 단다. 거는 곳에 맞는 것 하나만 단다. 회전 받침에는 받침 발을 단 패널을 얹는다.
- **모터.** 28BYJ-48 과 ULN2003 은 돌판 때 산 것 가운데 하나를 회전 받침에 쓴다. 새로 사지 않는다.

## 3. 더 나은 부품

| 바꿀 것 | 얻는 것 | 잃는 것 | 판단 |
|---|---|---|---|
| 안테나 4개로 먼저 (스위치 1 + 위상 2) | 관문 4 의 돈 대부분을 쓰기 전에 두 대역 방향을 실물로 본다 | 약 3만 원 더, 하루 | 관문 3 다음에 한다 |
| RF 모듈 일곱을 기판 하나로 | 통이 얇아지고, 선이 줄어 위상 오차가 준다 | RF 기판을 설계하고 맞춰야 한다 | 패널이 된 뒤 |
| 사 오는 2.4 GHz 판 (CoreHW CHW1010-ANT2) | 판이 검증되어 있다 | 5 GHz 를 못 잰다, 약 12만 원, 6주 | 두 대역 판이 끝내 안 될 때만 |
| ESP32 둘의 시계를 묶어 위상을 직접 잰다 (ESPARGOS 방식) | 패킷이 4분의 1 로 준다 | 칩을 떼어 붙여야 한다 | 하지 않는다 |
| 패널을 셋으로 | 강의실에서 한 번에 더 맞힌다 | 약 40만 원 더 | 하지 않는다 |

## 4. 돌판 부품은 어떻게 하나

모터 둘, 드라이버 둘, 알루미늄 판, 동전, 스탠드는 사지 않는다. 모터와 드라이버 한 벌만 회전 받침에 쓴다. 관문 2 가 끝내 안 되어도 돌판으로 돌아가지 않고 받는 쪽만 바꾼다 (Intel AX210 카드 3~5만 원과 미니 PC, [되는지 근거와 대안](되는지%20근거와%20대안.md)). 돌판의 부품 목록은 [receiver-legacy](https://github.com/DeteCam/receiver-legacy) 에 보관만 한다.
