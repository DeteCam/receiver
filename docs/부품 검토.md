# 부품 검토: 패널 수신기에 필요한 것, 겹치는 것, 더 나은 것

2026-11-17 기준. 부품의 수와 값은 [부품표](부품표.md)에, 구조를 바꾼 까닭은 [설계 검토](설계%20검토.md)에 있다. 이 글은 네 가지 물음에 답한다.

## 한눈에

| 물음 | 답 |
|---|---|
| 지금 부품으로 할 일을 다 하나 | 계산으로는 한다. 실물에서 두 가지(ACK 의 CSI, 세기로 위상 되찾기)가 되어야 한다. 사기 전에 확인한 것은 [사전 검증](사전%20검증.md) |
| 겹치는 부품이 있나 | 탐지용 동글은 패널의 ESP32-C5 와 겹쳐 보이지만 빼지 않는다 (2026-11-18). 패널의 ESP32-C5 는 위치를 재는 동안 한 채널에 묶여 채널을 돌며 엿들을 수 없다. 5 GHz 는 탐지만 하므로 탐지가 확실해야 한다 |
| 더 싼 구성이 있나 | 안테나를 4개로 줄이면 패널마다 9만 원쯤 싸고 옆자리까지 4~8점 낮다. 세기만 재는 값싼 수신기 여러 개는 자리를 못 맞힌다 ([사전 검증 4절](사전%20검증.md#4-더-싸게-더-확실하게-견준-구성)) |
| 더 나은 부품이 있나 | 안테나 판을 직접 만들면 간격을 넓힐 수 있다 (책상 위 70 → 76%). RF 모듈 넷은 작은 기판 하나로 줄일 수 있다. 둘 다 패널이 실물에서 된 뒤의 일이다 |
| 먼저 살 것 | ESP32-C5 두 개, 3만 원. 그다음은 통과할 때마다 3.6만 → 5.3만 → 15.4만 → 26.7만 원 ([부품표](부품표.md#사는-순서-관문)) |

## 1. 부품마다 하는 일

| 부품 | 하는 일 | 없으면 |
|---|---|---|
| 안테나 배열 보드 (패치 16 + 스위치) | 같은 전파를 16자리에서 받는다. 자리마다의 위상 차이가 방향이다 | 방향을 못 잰다 |
| 기준 안테나 (ESP32 에 딸려 온 것) | 위상의 기준. 고른 안테나와 합쳐 세기를 잰다 | 패킷마다 위상 기준이 달라 안테나끼리 견줄 수 없다 |
| U.FL 잭 - SMA 수 변환 단자 | 기준 안테나의 선(U.FL 플러그)을 스위치(SMA 암)에 바로 꽂는다 | 변환선도 끝이 플러그라 안테나의 선과 끼워지지 않는다 |
| 짧은 SMA 선 (수-수) | 스위치 B 와 합침기를 잇는다 | 둘 다 SMA 암이라 그냥은 안 끼워진다 |
| RF 스위치 모듈 둘 + 길이가 다른 선 넷 | 기준 길의 위상을 0·90·180·270도로 바꾼다 | 위상의 부호를 모른다 (좌우가 뒤집힌 답이 함께 나온다) |
| 합침기 | 기준과 고른 안테나를 더한다 | 세기에 위상이 담기지 않는다 |
| ESP32-C5 | 스위치를 돌리고, 빈 프레임을 보내고, 응답의 세기(CSI)를 잰다 | - |
| 허브 (파이 + 동글 둘 + 배터리) | 둘레를 엿들어 의심 기기를 고르고, 패널이 잰 것을 모아 자리를 내고, 폰에 보여 준다 | 탐지와 계산을 할 곳이 없다 |

## 2. 겹치는 부품

- **라디오 넷.** 파이의 Wi-Fi, 동글 둘, 패널의 ESP32 둘. 동글 하나는 폰과의 통신에, 하나는 엿듣기에 쓴다. 패널의 ESP32 도 엿들을 수 있으므로 탐지용 동글과 일이 겹친다. 다만 사진만 가끔 보내는 카메라를 놓치지 않으려면 채널을 지키는 라디오가 많을수록 좋다. 그래서 빼지 않는다.
- **배터리.** 허브 가까이 거는 패널은 허브에서 USB 로 전원을 받는다. 먼 패널만 18650 을 쓴다.
- **걸이.** 자석 걸이판과 받침 발은 같은 구멍에 단다. 거는 곳에 맞는 것 하나만 단다.

## 3. 더 나은 부품

| 바꿀 것 | 얻는 것 | 잃는 것 | 판단 |
|---|---|---|---|
| 안테나 판을 직접 만든다 (간격 61 mm, 250 mm 판, 스위치 칩 CHW1010 약 1만 원) | 책상 위 70 → 76% | RF 기판을 설계하고 맞춰야 한다 | 패널이 된 뒤 |
| 보드를 둘 이어 붙인다 (4 × 8) | 70 → 72% | 12만 원 더 | 하지 않는다 |
| 패치 4개짜리 보드 (CHW1010-ANT3) | 조금 싸다 (약 10만 원) | 높이를 가르는 힘이 준다. 계산하지 않았다 | 하지 않는다 |
| RF 모듈 넷을 기판 하나로 (합침기 + 위상 4단) | 통이 얇아지고 선이 준다 | 기판 설계 | 패널이 된 뒤 |
| ESP32 둘의 시계를 묶어 위상을 직접 잰다 (ESPARGOS 방식) | 패킷이 4분의 1 로 준다 | 칩을 떼어 붙여야 한다 | 하지 않는다 |
| 패널을 셋으로 | 강의실에서 한 번에 56 → 63%, 여덟 번에 81 → 89% | 25만 원 더 | 강의실에서 쓸 때 |

## 4. 돌판 부품은 어떻게 하나

모터 셋, 드라이버 셋, 알루미늄 판, 동전, 스탠드는 사지 않는다. 관문 2 가 끝내 안 되어도 돌판으로 돌아가지 않고 받는 쪽만 바꾼다 (Intel AX210 카드 3~5만 원과 미니 PC, [되는지 근거와 대안](되는지%20근거와%20대안.md)). 돌판의 부품 목록은 [receiver-legacy](https://github.com/DeteCam/receiver-legacy) 에 보관만 한다.
