> [!TIP]
> **드롭인 대안 2가지 (설계 변경 0%)**
> 1. **x86 SBC 대안**: ARM64 커널 빌드 대신 기존 x86을 원하면 `Radxa X4 (N100)`가 동일한 `85×56 mm / 58×49 mm` 홀 규격으로 그대로 들어갑니다.
> 2. **Pilot 1단계 0-납땜 대안**: JLCPCB PCBA 전 빠른 시험용으로 `Molex 146153-0100 (34.9×9 mm)` 12+1소자 배열(`Palm-12-Molex`, 2.45G `2.18°` / 5.2G `0.71°`)도 동일 크기에서 검증 완료했습니다.

## 2. 단계별 관문 구매 전략 (리스크 최소화)

1. **관문 1 (약 9.5만 원)**: `Radxa ROCK 3A` 1대 + `AX210` 1개 + `microSD` 1개 → `VesperCSI` 2.4/5 GHz 160 MHz CSI 수신·버스트 유지율 실측 확인.
2. **관문 2 (약 18.2만 원)**: `112×112 mm` 4층 통합 RF PCB 5매 제작(3매 SMT) → 보유 스텝모터 턴테이블로 1회 회전 측정하여 상호결합 역행렬 `C⁻¹` 및 2.45/5.2 GHz AoA 정확도 실측 검증.
3. **관문 3 (약 19.0만 원)**: 나머지 2노드(`ROCK 3A×2`, `AX210×2`, 자석·나노겔·차폐시트·볼트) 구매 + 3기 1판씩 총 3판 출력 → 6대 공간 현장 검증!
