# 빠른 시험: 하루 만에 큰 위험 넷을 본다

두 대역 판의 큰 위험 다섯 가운데 넷은 스위치와 합침기 없이도 볼 수 있다. ESP32-C5 두 개와 필름 안테나 열 개만 사서 하루에 본다. 스위치가 필요한 '세기로 위상 되찾기'만 나중으로 미룬다.

| 위험 | 이 시험에서 | 남는 것 |
|---|---|---|
| ESP32-C5 의 CSI 세기가 고른가 | 시험 1 | ACK 의 CSI (관문 1 의 나머지) |
| 안테나끼리 간섭 (33 mm, 2.4 GHz 에서 0.27 파장) | 시험 2, 3 | - |
| 반사판 거리 하나로 두 대역 | 시험 2, 3 | - |
| 5.8 GHz 에서 34도 밖이 헷갈림 | - (계산으로 안다) | 4개 판에서 확인 |
| 선 · 스위치의 위상 차이 | - | 조립 뒤 보정 (관문 4) |

손이 드는 시간: 시험 1 약 6분 (기다림), 시험 2 + 3 약 1시간. 받는 보드의 U.FL 은 처음에 한 번만 꽂는다.

## 1. 살 것 (오늘)

가장 빠른 길: **보드는 쿠팡(내일 도착), 필름 안테나는 Mouser(해외, 며칠)**. 보드가 오는 날 시험 1 을 하고, 안테나가 오면 시험 2 + 3 을 한다. 값과 도착일은 2026-11-19 오전에 쿠팡에서 본 것이고, 주문할 때 다시 본다.

| 무엇 | 어디 | 수 | 값 | 도착 | 쓰는 곳 |
|---|---|---|---|---|---|
| Waveshare ESP32-C5-MINI-KIT **-U** (U.FL 단자, 두 대역 FPC 안테나 딸림) | 쿠팡 9784357480 (판매 하이제니스) | 1 | 32,000원 | 11/20 (금) 예정 | 받는 쪽. 필름 안테나를 꽂는다 |
| ESP32-C5-DevKitC-1 N4 호환보드 (기판 안테나) | 쿠팡 9210295925 | 1 | 25,000원 | 11/20 (금) 예정 | 보내는 쪽 |
| Molex 146153-0100 필름 안테나 | Mouser 538-146153-0100 | 25 | 약 2,800원 | 며칠 (해외) | 시험 판 9개 + 남는 것은 관문 2 · 4 몫 |

- 받는 쪽 예비: HG ESP32-C5 DevKitC-1 N8R8 **외장안테나** (쿠팡 9732187552, 48,000원, 내일 도착 **보장**, 남은 수 적음). MINI-KIT-U 가 품절이거나 늦으면 이것.
- 보내는 쪽은 2.4 · 5 GHz 를 내는 ESP32-C5 보드면 아무것이나 된다. 받는 쪽만 U.FL 단자가 있어야 한다.
- XIAO ESP32-C5 는 쿠팡에서 해외 배송(12월 초)뿐이고, Mouser 도 재고가 없다. 디바이스마트에는 ESP32-C5 보드가 없다. 그래서 빼었다.
- Molex 146153 은 쿠팡 · 디바이스마트에 없다. Mouser 한국은 재고가 많고 6만 원 이상이면 배송비가 없다. 25개면 넘는다 (어차피 34개가 필요하다).
- 쿠팡의 다른 두 대역 안테나(투에이치앤에스 2.4/5.8 GHz, 3,000원, 내일)는 모양 · 크기가 달라 판 설계와 맞지 않는다. 시험 1 에는 받는 보드에 딸려 오는 FPC 안테나로 충분하다.
- 펌웨어는 두 가지다. USB 가 칩에 바로 붙은 보드와 변환 칩(CH340 등)을 거치는 보드. `flash.sh` 가 보고 고른다.

**같은 날 같이 주문해 둘 것 (시험 날까지 안 와도 된다, 알리익스프레스 1~2주):** HMC7992 SP4T 스위치 모듈 2, 2~6 GHz 2분배기(합침기) 1, SMA 수-수 짧은 선, U.FL-SMA 변환 단자. 관문 2 · 3 의 부품이다 ([부품표](부품표.md#사는-순서-관문)). 확실한 합침기는 Mini-Circuits ZN2PD-63-S+ (1.8~6 GHz) 인데 Mouser 에서 약 13만 원이고 재고가 없다.

**집에 있는 것으로:** 우드락 (5 mm, 150 x 150 이상) 두어 장, 두꺼운 종이, 쿠킹 호일, 양면테이프, 칼, 프린터, USB-C 선 2, 보조배터리.

## 2. 준비 (부품이 오기 전)

1. 노트북에: `pip install esptool pyserial numpy matplotlib`
2. [도안](../firmware/bench/도안.pdf) 을 **실제 크기(100%)** 로 인쇄한다. 1쪽 아래의 50 mm 자로 확인.
3. 우드락에 1쪽을 붙인다. 반사판(두꺼운 종이 150 x 150 + 호일)과 간격 기둥(우드락 3장 / 4장 / 6장 + 종이)을 만든다.
4. 2쪽(각도판)을 책상에 붙인다.

## 3. 펌웨어 올리기 (보드마다 1분)

```
cd firmware/c5/csi_probe
./flash.sh /dev/ttyACM0          # 보드를 하나씩 꽂고. 포트는 python3 ../../bench/probe.py ports 로 본다
```

미리 빌드한 파일(`bin/`)을 올린다. ESP-IDF 가 없어도 된다. 소스를 고쳤으면 ESP-IDF v5.5 로 `idf.py build` 한다.

그다음 두 보드를 함께 꽂고 역할을 준다 (한 번만, 보드에 남는다):

```
cd firmware/bench
python3 probe.py setup /dev/ttyACM0 /dev/ttyUSB0      # 앞 = 보내는 쪽, 뒤 = 받는 쪽 (U.FL 이 있는 보드)
```

## 4. 시험

모두 `firmware/bench` 에서 한다. 기록과 판정은 `firmware/bench/data/` 에 쌓인다.

### 시험 1: CSI 세기가 고른가 (약 6분)

```
python3 probe.py t1 보내는포트 받는포트
```

- 두 보드를 3 m 떨어뜨려 마주 보게 둔다. 받는 쪽에는 우드락 판의 1번 안테나(혼자)를 꽂아 둔다. 필름 안테나가 아직 없으면 받는 보드에 딸려 온 두 대역 FPC 안테나로 해도 된다 (이 시험은 칩을 본다). 시험 동안 둘 사이를 지나가지 않는다.
- 2.4 GHz (6번), 5.2 GHz (40번), 5.8 GHz (157번) 에서 1분씩 받는다. 이득을 그대로 둔 것과 묶은 것 두 번.
- **통과:** 이어진 두 패킷의 세기 차 가운데값 0.5 dB 안, 네 패킷(위상 한 번 재기) 안의 세기 폭 90% 가 2 dB 안, 초당 50개 이상. 기준은 [사전 검증](사전%20검증.md) 의 견디는 한계(이득 2 dB)에서 왔다.

### 시험 2 + 3: 간섭, 반사판, 돌린 무늬 (약 1시간, 안내를 따라)

```
python3 probe.py t2 보내는포트 받는포트
```

보내는 보드는 2 m 앞, 같은 높이. 방 가운데, 둘레 1 m 안에 금속이 없게. 안내 순서:

1. 1번 안테나만 붙인 판: 정면 세기 → (권함) 15도씩 24번 돌리며 무늬
2. 2~9번까지 붙인 판 (1번은 이웃 여덟, 실제 패널 안쪽과 같다): 정면 세기 → 돌린 무늬
3. 반사판 15 / 20 / 31 mm: 정면 세기 → 가장 나은 거리로 돌린 무늬 (앞뒤 차)

끝나면 판정 표와 `data/무늬.png` 가 나온다. 나중에 `python3 probe.py report` 로 다시 볼 수 있다.

## 5. 판정 기준과 그다음

간섭의 기준은 [sim/pre/coupling.py](../sim/pre/coupling.py) 에서 왔다. 4 x 4 판에서 이웃 결합을 -30 ~ -6 dB 로 바꿔 가며 방향 오차를 셈했다.

| 이웃 결합 | 시험 2 에서 보일 정면 세기 변화 | 시험 3 의 무늬 출렁임 | 보정 없이 (2.4 GHz, 가운데 / 90%) | 회전 받침으로 보정하면 |
|---|---|---|---|---|
| 없음 | 0 | 0 | 0.8 / 1.2도 | 같음 |
| -20 dB | 약 4 dB | 약 2.5 dB | 1.6 / 4.3도 | 0.8 / 1.3도 |
| -15 dB | 약 6 dB | 약 4 dB | 2.2 / 6.7도 | 0.8 / 1.3도 |
| -10 dB | 약 9 dB | 약 5 dB | 2.8 / 9.4도 | 0.8 / 1.3도 |
| -6 dB | 약 12 dB | 약 6 dB | 3.2 / 11.6도 | 0.8 / 1.3도 |

(5 GHz 도 비슷하거나 조금 낫다. 표의 숫자는 `sim/pre/coupling.json`. 6 m 거리에서 옆자리 사이는 약 6도다.)

| 시험 | 결과 | 그다음 |
|---|---|---|
| 1 | 세 대역 모두 통과 | 그대로 간다 |
| 1 | 이득을 묶어야 통과 | 패널 펌웨어에서 이득을 묶는다 (같은 함수) |
| 1 | 묶어도 실패 | 패킷을 더 모아 평균 (재기 0.3 → 1.2초). 그래도 안 되면 받는 쪽을 Intel AX210 + 미니 PC 로 ([되는지 근거와 대안](되는지%20근거와%20대안.md)) |
| 2 | 정면 세기 변화 4 dB 안, 출렁임 3 dB 안 | 보정 없이 된다 |
| 2, 3 | 그보다 크다 | 회전 받침으로 판의 실제 반응(실측표)을 재서 쓴다. 계산에서는 결합이 -6 dB 여도 보정하면 1.3도 안 |
| 2 | 1번 세기가 혼자일 때보다 10 dB 넘게 준다 | 안테나가 크게 어긋났다. 간격을 넓히거나(대역마다 장단점) 다른 안테나 |
| 2 | 반사판이 어느 거리에서도 한 대역을 1 dB 넘게 깎는다 | 31 mm (2.4 GHz 에 맞춤) 로 두고 5 GHz 손해를 받거나, 반사판을 빼고 앞뒤는 회전과 패널 둘로 가른다 |
| 3 | 앞뒤 차 10 dB 안 | 반사판 크기 · 거리를 다시 본다 |

## 6. 이 시험이 보지 못하는 것

- 받는 쪽이 안테나 하나라 **세기만** 본다. 결합이 위상을 얼마나 비트는지는 못 본다. 위의 기준은 '세기 변화가 이만하면 결합이 이만하다'는 계산에 기댄다.
- 이웃 안테나의 선 끝이 아무 데도 꽂히지 않은 채로 잰다. 실제 패널에서는 스위치에 꽂힌다. 반사가 조금 다를 수 있다.
- 방의 반사 때문에 무늬 하나하나는 울퉁불퉁하다. 그래서 판정은 '이웃 있음 / 없음'의 비율로 한다 (같은 자리, 같은 각도라 방의 영향이 지워진다).
- 5.8 GHz 의 헷갈림과 '세기로 위상 되찾기'는 스위치가 온 뒤 4개 판에서 본다.
- 펌웨어는 빌드(ESP-IDF v5.5.1, esp_csi_gain_ctrl 0.1.5)와 판정 코드(가짜 기록)까지만 확인했다. 실물에서는 아직 돌리지 않았다. 특히 5 GHz 에서 ESP-NOW 로 보내기가 되는지는 보드에서 처음 확인한다. 받는 쪽에 패킷이 하나도 안 오면 `probe.py` 의 출력과 보내는 쪽의 `I,tx,...` 줄을 보고 고친다.
