# 폴더와 파일

저장소 `receiver` 의 모든 폴더와 파일이 무엇인지 적었다. 처음이면 [README](README.md)의 순서대로 문서를 읽고, 코드를 고칠 때 여기서 찾는다.

## 한눈에

```
receiver/
├── README.md            첫 화면
├── docs/                문서 (옵시디언 볼트의 DeteCam 폴더)
│   ├── images/          그림
│   ├── videos/          동작·조립 영상 (깃허브 Pages)
│   └── simulator/       돌판 수신기의 3축 화면 (깃허브 Pages)
├── cad/                 3D 모델 코드
│   ├── model/           치수와 부품 모양 (panel.py)
│   ├── export/          STL·부품표·마커 내보내기
│   ├── checks/          겹침, 틈, 무게, 넘어지는 각
│   ├── figures/         확인용 그림, 조립 영상, 설계도와 데모 환경의 그림
│   ├── slicing/         Bambu Studio 슬라이싱과 G코드 검사
│   └── results/         검사 결과 (json)
├── stl/                 출력할 부품 8가지
├── print/               출력 파일: gcode/ (바로 출력), project/, preview/
├── marker/              AR 마커
├── firmware/            수신기 코드: core/ (계산) pi/ (허브) host/ tests/
├── sim/                 시뮬레이션: rt/ (교실과 숙소 방의 전파 경로 계산, 패널 연구)
│   ├── pre/             부품을 사기 전의 검증 (가진 기록의 분석, 결과 모음, 그림)
│   ├── direction/ location/ identify/     돌판 수신기 때의 계산
│   └── em/              돌판 수신기의 전파 계산
├── specs/               스펙: 기능마다 spec → plan → tasks
└── console/             돌판 수신기의 3축 화면 원본
```

**규칙.** 코드는 하는 일끼리 폴더로 묶었다. 계산 결과(json)는 그것을 만든 코드 가까이에 둔다. 지난 판의 파일은 두지 않는다 (깃 기록과 태그에서 찾는다). 돌판 수신기의 설계 파일(모델, STL, G코드, 조립 문서)은 태그 `plate-v2` 에 있다.

## 저장소 맨 위

첫 화면(README), 그리고 아래 폴더들

| 파일 | 하는 일 |
|---|---|
| `.gitattributes` | 줄바꿈과 이진 파일 표시 |

| `README.md` | 첫 화면: 생김새, 시뮬레이터, 개요, 폴더 |

## `firmware/core/` — 계산

`panel.py` 는 패널 수신기의 계산이다. 나머지는 돌판 수신기의 방향·위치 계산과, 그대로 쓰는 판별·의심 점수다.

방향·위치·판별 계산. 장치와 시뮬레이션(`sim/`)이 같은 코드를 쓴다

| 파일 | 하는 일 |
|---|---|
| `analyze3.py` | CSI 파일에서 방향을 구하는 처음부터 끝까지 |
| `estimator.py` | 여러 스캔의 곡선에서 방향(방위, 높이)을 구한다 |
| `fusion.py` | 스캔마다 꺼진 구간의 가운데를 읽고 합친다 |
| `identify.py` | 판별: 움직임에 전송량이 따라오는지 |
| `locate.py` | 여러 자리를 합쳐 추정 구간을 구한다 |
| `model.py` | 판이 만드는 회절 모형 (DiffLoc) |
| `score.py` | 의심 점수: 기기마다 증거(새로 나타남, 전송량, 송출 패턴, 걷기 반응, 핫스팟, 이름, 세기)를 쌓아 점수·등급·이유를 낸다. 점검(감시) 흐름에서 쓴다 |
