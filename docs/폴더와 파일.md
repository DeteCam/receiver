# 폴더와 파일

저장소 `receiver` 의 모든 폴더와 파일이 무엇인지 적었다. 처음이면 [README](README.md)의 순서대로 문서를 읽고, 코드를 고칠 때 여기서 찾는다.

## 한눈에

```
receiver/
├── README.md            첫 화면
├── docs/                문서 (옵시디언 볼트의 DeteCam/receiver 폴더)
│   ├── images/          그림
│   └── videos/          동작·조립 영상 (깃허브 Pages)
├── cad/                 3D 모델 코드
│   ├── model/           치수와 부품 모양 (panel.py)
│   ├── export/          STL·부품표·마커 내보내기
│   ├── checks/          겹침, 틈, 무게, 넘어지는 각
│   ├── figures/         확인용 그림, 조립 영상, 설계도와 데모 환경의 그림
│   ├── slicing/         Bambu Studio 슬라이싱과 G코드 검사
│   └── results/         검사 결과 (json)
├── stl/                 출력할 부품 12가지
├── print/               출력 파일: gcode/ (바로 출력), project/, preview/
├── marker/              AR 마커
├── firmware/            수신기 코드: core/ (패널 계산, 판별, 의심 점수) pi/ (탐지) host/ tests/
├── sim/                 시뮬레이션
│   ├── rt/              교실과 숙소 방의 전파 경로 계산 (패널 연구, 사각지대)
│   ├── pre/             부품을 사기 전의 검증, 사각지대의 숫자와 그림
│   └── identify/        판별 흉내
└── specs/               스펙: 기능마다 spec → plan → tasks (004, 006, 007)
```

**규칙.** 코드는 하는 일끼리 폴더로 묶었다. 계산 결과(json)는 그것을 만든 코드 가까이에 둔다. 지난 판의 파일은 두지 않는다 (깃 기록에서 찾는다). 돌판 수신기 때의 것(모델, STL, G코드, 허브 프로그램, 모터, 시뮬레이터, 전파 계산, 글)은 모두 [receiver-legacy](https://github.com/DeteCam/receiver-legacy) 에 있다.

## 저장소 맨 위

첫 화면(README), 그리고 아래 폴더들

| 파일 | 하는 일 |
|---|---|
| `.gitattributes` | 줄바꿈과 이진 파일 표시 |
| `.gitignore` | 깃에 넣지 않을 것 (다시 만들 수 있는 큰 중간 파일, 옵시디언 설정) |
| `README.md` | 첫 화면: 생김새, 동작 영상, 숫자, 폴더 |

## `docs/` — 문서와 그림

만들 때 읽는 문서. 옵시디언 볼트의 `DeteCam` 폴더가 바로 이 폴더다.

| 파일 | 하는 일 |
|---|---|
| `.nojekyll` | 깃허브 Pages 가 파일을 그대로 보여 주게 하는 표시 |
| `README.md` | 문서 모음의 첫 장 (노트 목록과 요약) |
| `index.html` | 깃허브 Pages 첫 주소 (동작·조립 영상으로 넘어간다) |
| `설계 검토.md` | 왜 돌판에서 패널로 바꿨나: 원인, 견준 방법, 정확도, 속도, 소음, AI, 남은 위험, 바탕 자료 |
| `사전 검증.md` | 부품을 사기 전에 확인한 것, 더 싼 구성과의 견줌, 싼 것부터 사는 순서(관문) |
| `설계도.md` | 시스템 구성, 패널 배선, 동작 순서, 소프트웨어 구조, 치수 |
| `데모 환경.md` | 강의실, 숙소 방, 탁상의 데모: 놓는 것, 순서, 통과 기준 |
| `숙소 방 계산.md` | 방에 숨긴 카메라의 자리를 패널로 찾는 계산 |
| `체크리스트.md` | 지금부터 할 일. 관문마다 사는 것과 실험 |
| `부품표.md` | 뽑는 부품과 사는 부품, 값 (`cad/export/partlist.py` 가 만든다) |
| `부품표.csv` | 부품표를 표 계산 프로그램용으로 |
| `부품 검토.md` | 부품마다 하는 일, 겹치는 것, 더 나은 것 |
| `조립 안내.md` | 패널과 허브 조립, 배선, 거는 법 |
| `폴더와 파일.md` | 이 문서 |
| `사각지대.md` | 패널 둘이 잘 못 맞히는 자리, 왜 거기인가, 거는 곳을 바꾸거나 하나 더 걸면 |
| `탐지와 판별.md` | 둘레에서 카메라 후보를 찾고(탐지), 이 방을 찍는지 가리기(판별) |
| `작품 범위.md` | 무엇을 하고 하지 않나 (필수 · 권장 · 선택 · 범위 밖), 정부 대책의 논란에 대한 답, 지금 설계로 되나, 목표 숫자 |
