# V1 시뮬레이션 사전 계획서 (2026-11-25)

> **목적**: [docs/AGENTS.md](https://github.com/DeteCam/docs/blob/main/AGENTS.md) 3.2절(바꾸기 전 동일 조건 비교)과 5장(시뮬레이션 규칙)에 따라, 결과를 보기 전에 장면 · 수신기 자리 · 카메라 자리 · 조건 · 평가 지표를 먼저 고정한다.

## 1. 비교 대상 (동일 장면 · 동일 광선 추적 데이터 · 동일 지표)

| 약칭 | 구조 · 알고리즘 | 비교 목적 |
|---|---|---|
| `Bartlett` | 기본 빔 합성 (`UCA-8 D=100 dz=0`, 50 Ω 흡수형 NEC2) | 학습/지도 없는 최소 기준선 (AGENTS.md 5.1.7) |
| `DiffLoc-Proxy` | 단일 안테나 CSI 진폭 회절 가림 모형 (동일 Sionna RT 경로 + 인체 동적 변동) | DiffLoc(단일 안테나 진폭 회절) 물리 원리 대조군 *(실제 DiffLoc 하드웨어 아님, V4 실측으로 대체 예정)* |
| `SPEC-002-NaiveFlip` | 기존 `UCA-8 D=100 dz=+65` + `MapModel` + **AX210 패킷당 π 반전 미보정** | 현재 설계 그대로 AX210을 썼을 때 붕괴 정량 확인 |
| `SPEC-002-NoFlip` | 기존 `UCA-8 D=100 dz=+65` + `MapModel` (π 반전 없는 이상 가정) | 기존 설계의 기하학/추정기 상한 기준 |
| **`SPEC-002+` (권고안)** | **`UCA-8+1 D=100 dz=0` (중심 기준 9번째 소자 통합, 높이 ≤18 cm)** + 50 Ω 흡수형 `PE42482` + **수동 RF 부호 앵커(`\|α\|=2.0`)** + **비게이팅 복소 비율 시간 평균** + **지도+대형 금속 반사체(칠판/거울)+Huber 강건 우도** | 본 개선 설계 (1자리 · 2자리 비동기 융합 각각 평가) |
| `SPEC-002++` | `UCA-12+1 D=100 dz=0` (13소자, 50 Ω 흡수형) + 동일 `SPEC-002+` 추정기 | 5 GHz 꼬리 오차가 남을 때의 고성능 상한 대조 |

### 실패 · 효과 없음 검증 대조군 (AGENTS.md 5.1.10)
1. **켤레곱 시간 평균** `mean(H_m * conj(H_ref))` vs **비게이팅 복소 비율 평균** `mean(H_m / H_ref)`
2. **진폭 게이팅(상위 70%) 비율 평균** vs 비게이팅 비율 평균
3. **반사형 OPEN 스위치** vs **50 Ω 흡수형 스위치**
4. **이상적 등방성 안테나(상한)** vs **NEC2 1.3.1 실제 안테나+금속 박스 패턴**

## 2. 도구 · 버전 · 물리 설정 (AGENTS.md 5.3절)

- **광선 추적기**: `Sionna RT 2.2.0` (`Mitsuba 3.9.1`, `Dr.Jit 1.5.0`, LLVM CPU polarized)
  - 반사 횟수 `max_depth = 4`, 투과 `refraction = True`, 회절 `diffraction = True`, `edge_diffraction = True`, 산란 `diffuse_reflection = True`
  - 광선 수 `samples_per_src = 100,000`, `max_num_paths_per_src = 300,000`, (카메라, 수신기) 쌍당 상위 80개 경로 저장
- **안테나 전파 해석**: `nec2c 1.3.1-2` (모멘트법)
  - 구리 도체 `5.8e7 S/m`, 하단 금속 박스 `90 × 90 × 35 mm` (호스트+스위치)
  - 비선택 포트 `50 Ω` 흡수형 종단(대조군: `1e6 Ω` 개방 반사형)
  - 주파수: `2437 MHz` (2.4 GHz), `5220 MHz` (5 GHz)
- **재질 출처**: ITU-R P.2040 (`concrete`, `plasterboard`, `wood`, `glass`, `metal`, `ceiling_board`, `floorboard`), 인체 조직(Gabriel/ITU 근육-수분 근사: 2.4 GHz `εr=52.7, σ=1.74 S/m`, 5.2 GHz `εr=49.3, σ=4.5 S/m`, 산란계수 `0.35`, 원기둥/블록 몸통+머리 메시), 목욕탕 수면(Debye 물: 2.4 GHz `εr=78.0, σ=1.5 S/m`, 5.2 GHz `εr=73.0, σ=5.2 S/m`). 칠판(`1200 × 3600 mm`) · 거울 · 금속 사물함 · 책상/의자 금속 다리 · 금속 수전/배관 = `metal`.
- **신호 생성기와 추정기 분리 (AGENTS.md 5.1.1, receiver AGENTS.md 3번)**:
  - 생성기(`sim/v1_ring/gen_scenes.py`)는 실제 3D 장면(사람 · 가구 · 미등록 금속 물체 포함)에서 경로를 만들고 저장한다.
  - 추정기(`sim/v1_ring/estimators.py`)는 생성기를 절대 임포트하지 않으며, 사용자가 AR로 알 수 있는 **오차가 섞인 방 크기 `(L, W, H)` + 수신기 위치/각도 + 눈에 보이는 대형 금속 반사체 1~2면(칠판/거울/사물함 면, ±0.15 m 오차)**과 보정된 NEC2 안테나 패턴만 입력받는다.

## 4. 대역 · 현실 오차 조건 · 사다리 표 (AGENTS.md 5.1.2 & 5.1.8)

- **대역 · 대역폭**:
  - **2.4 GHz** (`2.437 GHz`, 채널 폭 `20 MHz`, 유효 부반송파 52개)
  - **5 GHz** (`5.220 GHz`, 기본 `20 MHz` + 평가 장면에서 `40 MHz` · `80 MHz` 추가 비교)
- **기본 현실 오차 (전 장면 동일 적용)**:
  - 방 크기 오차 `σ_L,W = 0.15 m`, `σ_H = 0.075 m`; 대형 반사체 면 오차 `σ = 0.15 m`
  - 수신기 위치 오차 `σ_xy = 0.15 m`, `σ_z = 0.075 m`; 놓인 각도 오차 `σ_heading = 5.0°` (현장 보정 S5 적용 전·후 모두 보고)
  - 보정 후 포트 잔여 위상 오차 `σ_phase = 4.5°`, 진폭 오차 `σ_amp = 0.4 dB`, 상대 잡음 `SNR = 20 dB` (15 dB 스트레스 병기)
  - 측정 중 사람 움직임: 비직접파의 35%에 스윕당 위상 변동(`σ_dyn = 45°` @2.4G / `90°` @5G), `N_sweep = 10` 바퀴 누적
  - AX210 패킷당 무작위 $\pi$ 반전 (`s_p ∈ {-1, +1}`) 적용 → 수동 RF 부호 앵커(`|α| = 2.0`, 앵커 보정 오차 포함)로 복원
- **사다리 표 (AGENTS.md 5.1.8, `classroom_a` · `classroom_b` 2.4 & 5 GHz)**:
  - `L0`: 빈 방, 1차 반사만, 이상적 등방성 안테나, 오차 0
  - `L1`: + 4차 반사 · 회절 · 산란 · 투과
  - `L2`: + 가구 · 칠판 · 사물함 · 움직이는 사람 42명
  - `L3`: + NEC2 실제 안테나 + 금속 박스 (50 Ω 흡수형)
  - `L4`: + 현실 오차(위치/각도/방 크기/위상 지터/잡음/AX210 $\pi$-반전+부호 앵커) — 기존 `SPEC-002`
  - `L5`: + `SPEC-002+` 개선(중심기준 9소자 + 비게이팅 비율 평균 + 칠판 반영 + Huber 우도 + 2자리 융합)

## 5. 보고 지표 (AGENTS.md 5.1.4 & 5.5)
