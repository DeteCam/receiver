# 패널 연구 (sim/rt)

'스탠드 없이, 두 곳 이하'라는 조건에서 무엇이 정확도를 막는지 보고, 받는 쪽 구조를 견준 계산이다. 결론과 해석은 [설계 검토](../../docs/설계%20검토.md)에 있다. 여기에는 돌리는 법과 표의 출처를 적는다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `rt_paths.py` | 교실·강의실에서 놓는 곳마다, 카메라 점마다의 전파 길을 구한다 (Sionna RT, GPU). `--spots real` 2.2 m 까지의 스무 곳, `real2` 손이 닿는 스무 곳, `frame` 칠판 테두리, `lec2` 강의실 아홉 곳. `--pose 1` 이면 사람 자세를 섞는다 |
| `rt_study.py` | 같은 길 위에서 받는 쪽을 바꿔 가며 잰다. `measure`(재기), `table`(곳 조합의 표), `bearing`(방향 오차), `learn`(배운 모델) |
| `demo_run.py`, `demo_video.py` | 카메라 한 대를 따라가는 예와 그 영상 (`docs/videos/교실_동작_시뮬레이션.mp4`) |
| `study_figs.py` | 설계 검토의 그림 둘 |
| `run_pre.sh` | 구매 전 검증 계산: 세기 재기에 흔들림을 넣었을 때, 더 싼 구성(안테나 4개·8개, 수신 넷이 한꺼번에), 패널 하나 → `study/log_pre.txt` |
| `rt_rss.py` | 세기만 재는 값싼 수신기 여러 개로 자리를 맞히는 계산 (거리만으로 / 미리 재 둔 값이 있을 때) |
| `scene_room.py`, `room_paths.py` | 숙소 방(3.6 × 5.4 m, 욕실)의 장면, 숨긴 곳 아홉 가지, 패널을 두는 곳 열한 가지와 그 전파 길 |
| `room_study.py`, `run_room.sh` | 숙소 방에서 숨긴 카메라의 자리를 패널로 찾기: `measure`(재기), `table`(재는 곳 조합의 표, `--fuse` 겹치는 법) → `study/log_room.txt` |
| `rt_common.py` | 위의 계산이 함께 쓰는 상수와 작은 함수 (자리 점, 자리 고르기). 돌판 때의 `rt_eval.py` 에서 패널 쪽이 쓰던 것만 옮겨 왔다 |
| `blind_study.py` | 사각지대: 자리마다 맞힌 비율, 거는 곳을 바꾸거나 하나 더 걸 때 → `../pre/blind.json` ([사각지대](../../docs/사각지대.md)) |

받는 쪽 이름: `uca8` 둥근 8개, `sar10` 돌려 합치기, `ura4x4` 패치 4 × 4 (간격 반 파장), `ura4x4p37.5` 간격 37.5 mm, 뒤에 `h` 를 붙이면 수신 길 하나로 세기만 재는 방식, `ap:top12` 칠판 테두리, `oracle2` 방향을 2도로 안다고 칠 때. 돌판(`plate`)은 [receiver-legacy](https://github.com/DeteCam/receiver-legacy) 의 `sim/rt` 에서 돈다 (여섯 곳, 2.4 m 스탠드의 계산 `rt_eval.py` 도 거기 있다).

## 돌리는 법

```
# 길 (묶음 하나에 1분쯤. 사람 자세가 다른 여덟 묶음)
for s in 1 2 3 4 5 6 7 8; do python rt_paths.py kr40_t_s$s --spots real2 --seed $((100+s)) --jitter 0.07 --pose 1; done
SETS="kr40_t_s1 kr40_t_s2 kr40_t_s3 kr40_t_s4 kr40_t_s5 kr40_t_s6 kr40_t_s7 kr40_t_s8"
OPT='{"mount":"hinge","tilt":15,"yaw_sd":2,"tilt_sd":1,"pos_sd":0.05,"nbear":150}'

# 재기: 같은 카메라를 여덟 묶음에서 (--same). 1680번에 80초 (11코어)
python rt_study.py measure --recv ura4x4p37.5h --n 560 --same --sets $SETS --tag t1 --opt "$OPT"

# 표: 두 곳 조합을 모두 견줘 좋은 차례로 / 전송을 1, 2, 4, 8번 모았을 때 / 방향 오차
python rt_study.py table --recv ura4x4p37.5h --tag t1 --best 2
python rt_study.py table --recv ura4x4p37.5h --tag t1 --combo 7,17 1,7 1,7,17 --tdiv 1 2 4 8
python rt_study.py bearing --recv ura4x4p37.5h --tag t1

# 배운 모델: 네 곳만 재서 18,000번, 물리 모델·배운 모델·곱한 것을 견준다
python rt_study.py measure --recv ura4x4p37.5h --n 6000 --sets $SETS --tag L3 --opt '{"mount":"hinge","tilt":15,"yaw_sd":2,"tilt_sd":1,"pos_sd":0.05,"spots":[1,7,11,17]}'
python rt_study.py learn --recv ura4x4p37.5h --tag L3 --combo 7,17 1,7 1,7,17 --epochs 40
```

`--opt` 의 값: `mount` 거는 방법 (`aim` 자리 한가운데를 똑바로, `hinge` 좌우로만 자리 쪽, `flush` 벽에 납작하게), `tilt` 숙인 각, `yaw_sd`·`tilt_sd`·`pos_sd` 앱이 아는 패널 자세의 오차, `dur` 재는 시간, `snr` 신호 대 잡음, `spots` 이 곳들만.

## 표의 출처

| 설계 검토의 표 | 꼬리표 | 조건 |
|---|---|---|
| 2절 돌판, 3절 견준 방법들 | `a` | `kr40_real_s1..s8` (2.2 m 까지의 스무 곳), 사람 자세 고름, 패널 자세 오차 없음. 돌판의 점수는 receiver-legacy 에서 냈다 |
| 5절 어디에 거나, 6절 모으기, 7절 | `t1` | `kr40_t_s1..s8` (손이 닿는 스무 곳), 자세 섞음, 방향 오차 2도 |
| 5절 벽에 납작하게 | `t3` | `mount=flush, tilt=0` |
| 11절 패널의 자세 | `t4`, `t5` | 방향 오차 0.5도, 4도 |
| 7절 짧고 잡음 많은 전송 | `t6` | `dur=0.15, snr=20` |
| 6절 강의실 | `lec` | `lec72_t_s1..s8` (`--room lec72 --spots lec2`) |
| 10절 배운 모델 | `L2`, `L3` | 2,700번, 13,500번으로 가르침 |
| 6절 모으기의 숫자 (2026-11-18 고침), 사각지대 2절 | `t1b` | `t1` 과 같은 조건, 두 곳(7, 17)만, 종류마다 카메라 500대 (`--n 4000`) |
| 사각지대 3절 (거는 곳 견주기, 패널 셋) | `t1c` | `t1` 과 같은 조건, 스무 곳 모두, 종류마다 카메라 300대 (`--n 2400`) |

놓는 곳의 번호 (`real2`): 0 칠판 윗변 왼쪽 끝, 1 가운데, 2 오른쪽 끝, 3 교탁 위, 4·5 앞 모서리 삼각대 1.6 m, 6·7·8 창 유리 앞쪽·가운데·뒤쪽 2.0 m, 9 창턱 1.05 m, 10 앞문 위, 11 복도 창턱 가운데, 12 뒷문 위, 13·14·15 사물함 위, 16 뒷벽 2.0 m, 17·18 복도 창턱 앞쪽·뒤쪽, 19 창 유리 맨 앞.

## 구매 전 검증과 숙소 방

```
./run_pre.sh        # 흔들림(이득, 위상 단계, 세기가 다른 패킷, 정수 비트, 잡음), 더 싼 구성, 패널 하나, 세기만 재는 수신기. 약 20분
./run_room.sh       # 숙소 방: 길 묶음 셋 → 재기 → 표. 약 2분
cd ../pre && python3 collect.py && python3 figs.py      # 숫자를 result.json 으로 모으고 그림을 그린다
```

`--opt` 의 `imp`: 세기 재기에 넣는 흔들림. `gjit` 패킷마다의 이득 (dB), `sjit` 서브캐리어마다 (dB), `pherr` 위상 단계의 오차 (도), `txp`·`txdb` 세기가 다르게 나오는 패킷의 비율과 크기, `q8` CSI 를 받는 정수의 비트 수, `rep` 단계마다 여러 번 재서 가운데값.

| 글의 표 | 꼬리표 | 조건 |
|---|---|---|
| 사전 검증 3절 흔들림 | `i_g1` … `i_badr` | `t1` 과 같은 길, 두 곳(7, 17)만, 흔들림 하나씩 |
| 사전 검증 4절 더 싼 구성 | `c1` | 받는 쪽 `ura2x2`, `ura1x4`, `ura2x4p37.5h`, `ura2x2h`, 네 곳(1, 7, 11, 17) |
| 사전 검증 4절 세기만 재는 수신기 | `rt_rss.py` | 같은 길의 세기만 써서 |
| 숙소 방 계산 | `room_study.py` | `room_s1..s3` (숨긴 자리를 다르게 뽑은 셋), 카메라 864번 |

```
# 사각지대 (카메라를 늘려 다시 센 것)
python rt_study.py measure --recv ura4x4p37.5h --n 4000 --same --sets $SETS --tag t1b --opt '{"mount":"hinge","tilt":15,"yaw_sd":2,"tilt_sd":1,"pos_sd":0.05,"spots":[7,17]}'
python rt_study.py measure --recv ura4x4p37.5h --n 2400 --same --sets $SETS --tag t1c --opt '{"mount":"hinge","tilt":15,"yaw_sd":2,"tilt_sd":1,"pos_sd":0.05}'
python blind_study.py && cd ../pre && python3 blind_fig.py          # -> ../pre/blind.json, docs/images/사각지대_자리지도.png
```

**`t1` 의 숫자는 카메라가 적었다.** `t1` 은 종류마다 카메라 70대였다. `t1b`(500대)로 다시 세니 한 번 잴 때 책상 위 · 가슴 · 안경이 69 · 52 · 62% 로, `t1` 의 70 · 56 · 70% 보다 가슴과 안경이 4~8점 낮았다. 문서의 숫자는 `t1b` 로 고쳤다.

길 묶음(`paths/`)과 점수 파일(`study/`)은 커서 저장소에 올리지 않는다. 문서와 그림이 쓰는 숫자는 `../pre/result.json`, `../pre/room_est.npz`, `../pre/blind.json` 에 모아 올린다.
