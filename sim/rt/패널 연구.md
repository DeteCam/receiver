# 패널 연구 (sim/rt)

'스탠드 없이, 두 곳 이하'라는 조건에서 무엇이 정확도를 막는지 보고, 받는 쪽 구조를 견준 계산이다. 결론과 해석은 [설계 검토](../../docs/설계%20검토.md)에 있다. 여기에는 돌리는 법과 표의 출처를 적는다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `rt_paths.py` | 교실·강의실에서 놓는 곳마다, 카메라 점마다의 전파 길을 구한다 (Sionna RT, GPU). `--spots real` 2.2 m 까지의 스무 곳, `real2` 손이 닿는 스무 곳, `frame` 칠판 테두리, `lec2` 강의실 아홉 곳. `--pose 1` 이면 사람 자세를 섞는다 |
| `rt_study.py` | 같은 길 위에서 받는 쪽을 바꿔 가며 잰다. `measure`(재기), `table`(곳 조합의 표), `bearing`(방향 오차), `learn`(배운 모델) |
| `demo_run.py`, `demo_video.py` | 카메라 한 대를 따라가는 예와 그 영상 (`docs/videos/교실_동작_시뮬레이션.mp4`) |
| `study_figs.py` | 설계 검토의 그림 둘 |
| `rt_eval.py`, `report.py`, `README.md` | 돌판 수신기의 계산 (여섯 곳, 2.4 m 스탠드) |

받는 쪽 이름: `plate` 돌판, `uca8` 둥근 8개, `sar10` 돌려 합치기, `ura4x4` 패치 4 × 4 (간격 반 파장), `ura4x4p37.5` 간격 37.5 mm, 뒤에 `h` 를 붙이면 수신 길 하나로 세기만 재는 방식, `ap:top12` 칠판 테두리, `oracle2` 방향을 2도로 안다고 칠 때.

## 돌리는 법

```
# 길 (묶음 하나에 1분쯤. 사람 자세가 다른 여덟 묶음)
for s in 1 2 3 4 5 6 7 8; do python rt_paths.py kr40_t_s$s --spots real2 --seed $((100+s)) --jitter 0.07 --pose 1; done
SETS="kr40_t_s1 kr40_t_s2 kr40_t_s3 kr40_t_s4 kr40_t_s5 kr40_t_s6 kr40_t_s7 kr40_t_s8"
OPT='{"mount":"hinge","tilt":15,"yaw_sd":2,"tilt_sd":1,"pos_sd":0.05,"nbear":150}'

# 재기: 같은 카메라를 여덟 묶음에서 (--same). 1680번에 80초 (11코어)
python rt_study.py measure --recv ura4x4p37.5h --n 560 --same --sets $SETS --tag t1 --opt "$OPT"

# 표: 두 곳 조합을 모두 견줘 좋은 차례로 / 전송을 1, 2, 4, 8번 모았을 때 / 방향 오차
python rt_study.py table --recv ura4x4p37.5h --tag t1 --best 2
python rt_study.py table --recv ura4x4p37.5h --tag t1 --combo 7,17 1,7 1,7,17 --tdiv 1 2 4 8
python rt_study.py bearing --recv ura4x4p37.5h --tag t1

# 배운 모델: 네 곳만 재서 18,000번, 물리 모델·배운 모델·곱한 것을 견준다
python rt_study.py measure --recv ura4x4p37.5h --n 6000 --sets $SETS --tag L3 --opt '{"mount":"hinge","tilt":15,"yaw_sd":2,"tilt_sd":1,"pos_sd":0.05,"spots":[1,7,11,17]}'
python rt_study.py learn --recv ura4x4p37.5h --tag L3 --combo 7,17 1,7 1,7,17 --epochs 40
```

`--opt` 의 값: `mount` 거는 방법 (`aim` 자리 한가운데를 똑바로, `hinge` 좌우로만 자리 쪽, `flush` 벽에 납작하게), `tilt` 숙인 각, `yaw_sd`·`tilt_sd`·`pos_sd` 앱이 아는 패널 자세의 오차, `dur` 재는 시간, `snr` 신호 대 잡음, `spots` 이 곳들만.

## 표의 출처

| 설계 검토의 표 | 꼬리표 | 조건 |
|---|---|---|
| 2절 돌판, 3절 견준 방법들 | `a` | `kr40_real_s1..s8` (2.2 m 까지의 스무 곳), 사람 자세 고름, 패널 자세 오차 없음 |
| 5절 어디에 거나, 6절 모으기, 7절 | `t1` | `kr40_t_s1..s8` (손이 닿는 스무 곳), 자세 섞음, 방향 오차 2도 |
| 5절 벽에 납작하게 | `t3` | `mount=flush, tilt=0` |
| 11절 패널의 자세 | `t4`, `t5` | 방향 오차 0.5도, 4도 |
| 7절 짧고 잡음 많은 전송 | `t6` | `dur=0.15, snr=20` |
| 6절 강의실 | `lec` | `lec72_t_s1..s8` (`--room lec72 --spots lec2`) |
| 10절 배운 모델 | `L2`, `L3` | 2,700번, 13,500번으로 가르침 |

놓는 곳의 번호 (`real2`): 0 칠판 윗변 왼쪽 끝, 1 가운데, 2 오른쪽 끝, 3 교탁 위, 4·5 앞 모서리 삼각대 1.6 m, 6·7·8 창 유리 앞쪽·가운데·뒤쪽 2.0 m, 9 창턱 1.05 m, 10 앞문 위, 11 복도 창턱 가운데, 12 뒷문 위, 13·14·15 사물함 위, 16 뒷벽 2.0 m, 17·18 복도 창턱 앞쪽·뒤쪽, 19 창 유리 맨 앞.

길 묶음(`paths/`)과 점수 파일(`study/`)은 커서 저장소에 올리지 않는다.
