# V1 스위치 고리 시뮬레이션 결과 보고서 (2026-11-25)

> **시뮬레이션이며 실측이 아니다 ([docs/AGENTS.md](https://github.com/DeteCam/docs/blob/main/AGENTS.md) 5.4 · 5.5절).**
> 이 보고서의 모든 숫자는 **계산값**이며, 목표 달성이나 실제 성능 근거로 쓰지 않는다. 설계 선택(`SPEC-002` vs `SPEC-002+` vs `SPEC-002++`)과 V2 최소 구매 시험(3~5만 원)으로 넘어갈 근거로만 쓴다.

## 1. 실험 설정 · 도구 · 완화 조건 (사전 계획서: [`plan_20261125.md`](../plan_20261125.md))

- **광선 추적기**: `Sionna RT 2.2.0` (`Mitsuba 3.9.1`, `Dr.Jit 1.5.0`, LLVM CPU polarized) — 반사 4차(`max_depth=4`), 투과(`refraction=True`), 모서리 회절(`diffraction=True, edge_diffraction=True`), 확산 산란(`diffuse_reflection=True`), `samples_per_src=100,000`, 쌍당 상위 80개 경로 보존(전력의 94.2~99.2%).
- **안테나 전파 해석**: `nec2c 1.3.1-2` (구리 `5.8e7 S/m`, 90×90×35 mm 금속 박스 포함, 비선택 포트 `50 Ω` 흡수형 vs 개방 반사형 대조, `2437 MHz` · `5220 MHz`).
- **신호 생성기 / 추정기 분리**: `gen_scenes.py` + `channel_sim.py`(실제 방 · 사람 · 미등록 금속 물체 · NEC2 응답 · AX210 $\pi$-반전 생성)와 `estimators.py`(오차가 섞인 방 크기 · 수신기 위치/각도 · 눈에 보이는 대형 반사체 1~2면 · NEC2 1회 보정표만 입력)를 완전 분리.
- **공간 · 표본 · 난수**: `AGENTS.md` 5.2절 6종 공간 × 2변형 + 최악 금속방 = **13개 장면**, 장면당 카메라 40곳 × 난수 3개(`seed=0,1,2`) × 4자리 = 장면 · 대역당 480회 단일 자리 평가(평가 9장면 합계 대역당 4,320회 단일 자리 / 1,080회 2자리 쌍 평가). 개발용 4장면(`classroom_a`, `lodging_a`, `restroom_a`, `locker_a`)과 평가용 9장면(미학습 공간 `강의실` · `목욕탕` 4장면 + 변형 B 4장면 + `worst_metal`)을 엄격히 분리.
- **현실 오차 조건**: 방 크기 `σ=15 cm`, 수신기 위치 `σ=15 cm`, 수신기 각도 `σ=5°`, 포트 위상 지터 `σ=4.5°`, 진폭 `0.4 dB`, `SNR=20 dB`, 비직접파 35% 인체 동적 위상 변동(`N_sweep=10`), AX210 패킷당 무작위 $\pi$ 반전 + 수동 RF 부호 앵커(`|α|=3.5`, Dev `classroom_a`에서 결정, 보정 오차 3°/0.25 dB 포함).
- **완화 조건 목록**: ① 각 대역 공진 반파장 다이폴 가정(실물 듀얼밴드 매칭 편차는 V3 실측 필요), ② AX210 RX0/RX1 독립 AGC 이득 단차 미포함(문서상 미확인 항목 → V2 시험 3에서 필수 실측), ③ `DiffLoc-Proxy`는 동일 Sionna RT 경로 위 단일 안테나 진폭 회절 모형(360° 전방위 허용으로 DiffLoc에 유리한 조건이며 실제 DiffLoc 장비 실측이 아님).

## 7. 믿어도 되는 것 · 예상과 달랐던 발견 · 믿으면 안 되는 것 (AGENTS.md 5.5절)

- **믿어도 되는 것 (설계 선택 근거)**:
  1. **AX210 $\pi$-반전 보정 필수**: 보정하지 않으면(`SPEC-002-NaiveFlip`) 전 공간 평균 30.8~31.6°(P95 73~77°)로 붕괴하며, 수동 RF 부호 앵커(`|α|=3.5`)가 전 13장면 · 양 대역에서 97.8~99.2% 부호를 복구함.
  2. **R8 준수 + 9소자 통합 이득**: 사전 등록 `SPEC-002+`(AX210 $\pi$-반전 포함, `dz=0`, 높이 ≤18 cm)가 이상적 무반전 · R8 초과 기존 `SPEC-002-NoFlip`(`dz=+65`, 23.5 cm)보다 2.4 GHz · 5 GHz 평가 9장면 전체에서 평균 · P95 · 최악 방 모두 우세함.
  3. **12+1 소자(`SPEC-002++`) 불필요**: 8+1 대비 평가 평균 차이는 0.3~0.5°에 불과하고 5 GHz 2자리 P95는 오히려 악화되어(37.6° vs 36.7°), +10만 원 · 2단 스위치 손실을 감수할 가치가 없음.
  4. **2자리 결합(특히 대각 배치 `(0,3)`)의 효용**: 평가 9장면 통합에서 2자리 대각 `(0,3)`은 2.4 GHz `8.2°`(P95 `25.8°`), 5 GHz `8.2°`(P95 `30.0°`)로 1자리 및 인접 `(0,1)`보다 일관되게 안정적임(단, 앞벽 칠판 교실·강의실 A는 앞쪽 인접 `(0,1)`이 유리).
  5. **5 GHz 채널 폭 효과**: 20 → 40 → 80 MHz로 넓어질수록 2자리 오차가 `9.2° → 8.8° → 8.0°`(P95 `31.1° → 27.0°`)로 단조 개선됨.
- **예상과 달랐던 5장 대조군 발견 (가설 수정 및 단순화 — AGENTS.md 4장 · 5.1.10절)**:
  1. **$|H_{\text{ref}}|^2$ 가중 켤레곱 평균(`Conj-Avg`)이 비가중 비율 평균(`Ratio-Avg`)을 앞섬**: 당초 동적 산란 편향 때문에 `Ratio-Avg`가 유리할 것으로 가정했으나, 실제 Sionna RT 다중경로 + 열잡음 + ~1% 부호 오차에서는 기준 안테나 딥 페이드(`|H_ref|≈0`)의 `1/H_ref` 잡음 폭주가 훨씬 치명적이었다. `Conj-Avg`는 4장면 대조에서 2.4 GHz P95를 `-4.9°`, 5 GHz 2자리 P95를 **`-13.6°`** 줄였고, 사후 확인(6.5절)에서도 Dev · Eval 양쪽 모두 일관되게 개선되었다.
  2. **무제약 대형 반사체 면 추가(`Reflector-Map`)는 이득 없음**: 방 크기 · 위치 오차 15 cm가 섞인 상태에서 무제약 능형 회귀에 칠판 · 거울 거울상을 추가하면 자유도 과다로 `No-Reflector-Map`(6면 단순 지도)보다 0.1~0.4° 오히려 악화되었다. 물리적 반사율 제약이 검증되기 전까지는 **단순 6면 방 지도**를 기본으로 두고 반사체 입력은 선택/실험 기능으로 낮춘다.
  3. **고리 지름 `D=85 mm` vs `D=100 mm` 맞바꿈**: `D=85 mm`는 5 GHz 인접 소자 간격을 `0.566λ`로 줄여 5 GHz 대조군 P95를 `-10.1°` 개선하고 외경을 ~9.5 cm로 축소했다. 사후 전 장면 비교(6.5절)에서 `D100+Conj`는 2.4 GHz가 `0.2~0.4°` 근소 우세, `D85+Conj`는 5 GHz 1자리/인접이 `0.2~0.3°` 우세 + 크기 1.5 cm 소형화다(V3 3D 프린트 직전 0원 선택 가능).
  4. **개방 반사형 스위치(`Reflect-OPEN-SW`)**: 1회 정밀 NEC2 패턴 보정표를 완벽히 적용한 조건에서는 50 Ω 흡수형과 오차 차이가 작았다(0.1~0.3°). 다만 `PE42482` 50 Ω 흡수형은 내장 All-Off 50 Ω 종단(부호 앵커 실시간 보정)과 단일칩 1.1–1.4 dB 저손실 장점이 유지되므로 1순위를 유지한다.
- **믿으면 안 되는 것 (실측 필요 항목)**:
  1. 이 숫자는 시뮬레이션 **계산값**이며 DiffLoc+ 논문 실측값(`11.92°`)과 직접 비교해 '목표 달성'이라 쓰지 않는다(AGENTS.md 5.4절).
  2. AX210의 RX0/RX1 **독립 AGC 이득/위상 단차**와 실물 `PE42482`의 6 GHz 포트 위상 비대칭, 듀얼밴드 다이폴 매칭 편차는 시뮬레이션에 전부 담기지 않았으므로 **V2(3.5~5만 원) → V3 → V4 실측**으로 검증해야 한다.
