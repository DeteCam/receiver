# 001 방향 찾기: 방법

## 흐름

```
패킷(CSI) ──▶ analyze3.scan_curve ──▶ 신호 곡선 (72칸)
                                          │
기준 곡선 표 (sim/em/tables/*.npz) ──▶ 곡선 맞추기 ──▶ 방향마다의 가능성
머리 자세 (estimator.frame)        ──┘
```

## 곡선 맞추기

1. 기준 표에서 후보 방향마다 곡선을 꺼낸다. 표는 판 각도 72칸 × 위아래 37칸 × 좌우 72칸 × 편파 2개다.
2. 잰 곡선과 기준 곡선을 각각 평균을 빼고 크기를 맞춘 뒤, 둘의 닮은 정도(상관)를 구한다.
3. 편파 가정 14개마다 2를 되풀이하고, 한 곳의 스캔 전부에 같은 가정을 적용했을 때 가장 잘 맞는 것을 쓴다.
4. 닮은 정도를 가능성으로 바꾼다. 얼마나 날카롭게 바꿀지를 정하는 값(`den`)은 계산으로 160 을 골랐다.

곡선은 두 가지를 같이 쓴다. 변화가 큰 부반송파의 가운데값 곡선과, 부반송파 전체의 평균 세기 곡선이다. 교실 계산에서 평균 세기 곡선 + 편파 가정이 가장 좋았다.

## 지금 코드와 다른 점

| 지금 (`fusion.Fusion.read`) | 바꿀 것 |
|---|---|
| 곡선의 골 위치를 방향으로 읽는다 | 곡선 전체를 기준 곡선과 견준다 |
| 방향 하나를 낸다 | 방향마다의 가능성을 낸다 |
| 표가 없어도 돈다 | 표가 꼭 있어야 한다 (계산 표 → 실물 보정) |

계산에 쓴 구현은 `sim/rt/rt_eval.py` 의 `TM` 에 있다. 이것을 `firmware/core/estimator.py` 로 옮긴다.

## 보정 (실물 기준 곡선)

가리는 것 없는 곳에서 카메라를 3m 에 두고, 받침을 15° 씩 돌려 가며 스캔한다. 머리 숙임 세 가지로 되풀이한다. 얻은 곡선으로 계산 표의 크기와 어긋난 각도를 고치고, 많이 다르면 잰 곡선으로 표를 바꾼다.
