# PLAN-002: 스위치 고리 수신기 — 어떻게

## 1. 계산으로 먼저 정할 것 (V1)

1. **안테나 간섭**: `sim/em/`에 8소자 고리 + 기준 안테나 + 금속 몸체 NEC2 모델을 만든다. 고리 지름(8 · 9 · 10 cm), 기준 안테나 높이, 금속 거리를 바꿔 가며 계산한다. 다른 안테나가 50 Ω으로 끝나 있을 때와 스위치가 반사형일 때를 모두 본다.
2. **보정표**: 고리가 대칭이므로 안테나 하나의 수신 모양을 각도만 돌려 8개에 쓴다. 대칭이 깨진 정도(제작 오차)를 넣어 보정 뒤 남는 오차를 계산한다.
3. **방 전체**: 위 응답을 광선 추적 데이터에 넣어 교실 · 숙소 · 처음 보는 방(개발에 안 쓴 장면)에서 방향 오차를 계산한다. 자리와 조건은 `sim/plan_YYYYMMDD.md`에 먼저 적는다. 기본 빔 합성과 같은 틀에서 비교한다.

## 2. 실측 순서 (V2~V4)

| 단계 | 장비 | 측정 |
|---|---|---|
| V2 | 집 PC + AX210 + 안테나 2개 | 두 단자 CSI 수, 위상 안정성, 재부팅 뒤 위상 관계 |
| V3-a | + 스위치 모듈 1개, 안테나 4개, Pico | 전환 직후 CSI 버림 시간, 4소자 방향 |
| V3-b | 8소자 고리 1기 | 회전 받침으로 한 바퀴 돌려 보정표 만들기, 빈 방 3 m 방향 오차 |
| V4 | 고리 1기 + DiffLoc 재현 장비 | 교실 · 반사 많은 방, 미리 정한 자리 20곳 이상 번갈아 측정 |

## 3. 위험과 대응

| 위험 | 대응 |
|---|---|
| AX210 두 단자 위상이 흔들림 | V2에서 바로 확인. 실패하면 3장(AGENTS.md)의 방향을 다시 검토 |
| 안테나 간섭이 커서 보정이 안 됨 | 고리 지름 키우기, 안테나 사이 흡수재, 소자 수 줄이기를 계산으로 비교 |
| 스위치 전환과 패킷 시각 맞추기 | 50 Ω 끝단을 한 칸 두어 "신호 없는 칸"으로 순서를 데이터에서 확인 |
| 카메라가 패킷을 드물게 보냄 | 한 바퀴 시간을 짧게(0.5초 이하) 두고 여러 바퀴 평균 |
