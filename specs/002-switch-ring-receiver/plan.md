# PLAN-002: 스위치 고리 수신기 — 어떻게

마지막 수정 2026-11-26. 숫자는 모두 시뮬레이션 계산값이며 실측이 아니다.

## 1. 계산으로 정한 것 (V1, 끝남)

계획서 · 코드 · 결과는 [`sim/`](../../sim/README.md)에 있다.

| 정한 것 | 근거(계산값) |
|---|---|
| 16소자 지름 12 cm 고리 | 8소자 9~10 cm보다 위치 오차가 0.08~0.20 m 작음. 5 GHz에서 소자 간격이 반파장보다 좁아짐 |
| 끄덕이는 머리(−20° · 0° · +20°) | 스탠드와 한 축 레일을 없앰. 세로축 회전으로 바꾸면 한 번 잰 방향이 9.8% 나빠짐 |
| 앵커 배치 H4(스위치 공통 포트 뒤 6 dB 감쇠기) | 부호 복원 H1 86% → H4 97% |
| 체인 B 입력 6 dB 감쇠기 + "센 쪽 = 기준 체인" | 예전 규칙은 H4에서 거꾸로 동작(틀린 패킷 78%, 방향 평균 35°). 바꾸면 틀린 패킷 4%, 방향 13.1°(뒤바뀜이 없을 때 13.0°) |
| 수신기 1기를 여러 자리로 | 같은 자리 수면 2기 동시와 계산 결과가 같고 값은 절반 |
| 레거시 돌판으로 바꾸지 않음 | 한 자리 방위각 평균 고리 8.4° 대 돌판 18.3°(같은 장면, 2.4 GHz) |
| 구조는 그대로 둠 | 새 방 16개에서 구조 후보 9개(큰 지그재그 고리 + 세로축 회전, 평평한 큰 고리 등)가 채택 기준(방향 −10%)을 넘지 못함 |

새 방 16개에서 남은 것: 한 자리에서 한 번 잰 방향은 평균 13.8~16.3°로 기준선(8.92°)을 넘지 못했다. 원인은 가림이며, 여러 자리를 합친 "융합 방향"(4.4~5.4°)과 신뢰도 판정 · "더 재기"로 줄인다. 이 절차는 [ai 저장소](https://github.com/DeteCam/ai)에 있다.

## 2. 벤치 순서 (1기분을 먼저 사서)

1. 호스트 첫 부팅: `lspci`로 AX210 인식, 펌웨어(ucode) 번호, `rfkill list`. CSI 드라이버 빌드 · 적재
2. BLE 연결 판가름: CSI 드라이버를 올린 채 CM4 내장 BLE로 폰과 연결, 측정 중 송신 영향 확인. 안 되면 Pico W
3. 2.4 GHz · 5 GHz 캡처: 가진 카메라의 프레임에서 두 단자 CSI 수와 위상 안정(FR-1 · FR-2)
4. 전원: PD 9 V 시동, 보조배터리 자동 꺼짐, 벅 출력
5. SP16T 입고 검사: 반품 기간 안에 16포트 손실 · 격리 · 전환 시간 · 제어 진리표
6. 손실 · 앵커 · 체인 가르기: 감쇠기 0 · 6 · 10 dB로 부호 복원(FR-4), 세기 차 0 · 3 · 6 · 10 dB로 CSI 행 순서(FR-5)
7. 기계: 필름 부착, 웜기어 처짐, 끄덕이기 각도, 소음
8. 열 · 계산 시간

## 3. 실측 단계 (V2~V4)

| 단계 | 장비 | 측정 |
|---|---|---|
| V2 원리 확인 | CM4 + AX210 + 안테나 2개 | 두 단자 CSI가 초당 30개 이상, 위상 차가 1분 동안 5° 이내. 2.4 GHz와 5 GHz 카메라 각각 |
| V3 고리 1기 빈 방 | 16소자 고리 1기 | 보정표 만들기, 3 m에서 방향 오차 5° 이내, 측정값이 보정표 모형과 맞는지 |
| V4 교실 · 반사 많은 방 | 고리 1기 + DiffLoc 재현 장비 | 미리 정한 카메라 자리 20곳 이상에서 번갈아 측정. 가구 뒤 · 칸 안 · 상자 안 · 유리 뒤 카메라를 넣고 자리마다 지도 퍼짐과 오차를 기록 |

## 4. 위험과 대응

| 위험 | 대응 |
|---|---|
| AX210 두 단자 위상이 흔들림 | V2에서 바로 확인. 실패하면 docs 현재_방향.md의 방향을 AGENTS.md 3장 절차로 다시 검토 |
| 받은 CSI가 어느 포트 것인지 모름 | 시간 기록과 전환 순간 세기 변화를 함께 쓰고, 포트당 5패킷 이상 모은다. 알려진 송신기로 순서를 확인 |
| SP16T가 사양과 다름(손실 · 진리표) | 사기 전에 판매자에게 묻고, 입고 검사를 반품 기간 안에 끝낸다 |
| 앵커 마진이 모자라 부호가 뒤집힘 | 감쇠기 값을 벤치에서 고른다(0 · 6 · 10 dB) |
| CSI 행이 세기 순이 아님 | CSI 헤더의 체인별 수신 세기와 견줘 다른 가르기 방법을 찾는다 |
| 필름 안테나 사이 결합이 보정으로 안 잡힘 | 막대 안테나(예전 후보)로 되돌리는 안을 계산과 벤치로 비교 |
| 측정 중 무선 연결이 채널을 방해 | 벤치에서 측정 중 BLE 송신의 영향을 잰다. 방해가 보이면 Pico W로 바꾼다 |
| 금속면 가까이 두면 소자 위상이 바뀜 | 유전체용 · 금속용 보정표를 따로 둔다. 남은 경우는 NEC2로 다시 계산 |
| 카메라가 패킷을 드물게 보냄 | 자리당 재는 시간을 늘리거나 자세 수를 줄인다. 벤치에서 사진 업로드 패킷 수를 잰다 |
