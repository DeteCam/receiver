# PLAN-002: 스위치 고리 수신기 (`SPEC-002+`) — 어떻게

## 1. 계산으로 먼저 정할 것 (V1)

1. **안테나 간섭 · 기하학 (`sim/em/ring_nec2.py`)**: 8소자(`D=100 mm`, `D=85 mm`) 및 12소자(`D=100 mm`) 고리 + 중심 기준 안테나 + 90×90×35 mm 금속 박스의 NEC2 3D 패턴을 `2437 MHz` · `5220 MHz`에서 계산한다. 비선택 포트 `50 Ω` 흡수형과 개방 반사형(`1e6 Ω`)을 비교하고, 중심 기준 안테나를 9번째 가상 소자로 통합했을 때의 부엽(PSLL) 및 다중경로 오차를 검증한다.
2. **6종 공간 Sionna RT 검증 (`sim/plan_20261125.md`, `sim/v1_ring/`)**: `AGENTS.md` 5.2절 6종 공간(강의실 · 교실 · 숙소 · 화장실 · 목욕탕 · 탈의실) × 2변형 + 최악 금속방(13장면, 2.4 & 5 GHz, 난수 3개, 4차 반사 · 투과 · 회절 · 산란)에서 `Bartlett`, `DiffLoc-Proxy`, 기존 `SPEC-002`, 개선 `SPEC-002+`, 상한 `SPEC-002++(12+1)`을 동일 조건에서 비교한다. 개발(4장면)과 평가(9장면, 미학습 공간 2종 포함)를 엄격히 나누고 사다리 표(L0~L5) 및 실패 대조군을 함께 보고한다.

## 3. 위험과 대응

| 위험 | 대응 |
|---|---|
| AX210 패킷당 $\pi$-반전 및 RX0↔RX1 스왑 | 수동 RF 부호 앵커(`\|α\|=3.5`) + 비대칭 동축 지연으로 복원. V2에서 6–10 dB 독립 AGC 변동까지 직접 검증하고 실패 시 MediaTek `AW7915`(\$30) 백업 검토 |
| `FeitCSI` 5 GHz 버그 · 타임스탬프 0 · 유실 | **`VesperCSI` + `FeitCSI-iwlwifi` `#21` 패치 + Linux 6.12 LTS(`CPTCFG_IWLMLD=n`)** 사용 |
| `FeitCSI-iwlwifi`로 인한 RPi 5 내장 Wi-Fi 먹통 · 10 cm RF 포화 | **Burst-TDM**(측정 중 제어 무선 정지) + `cfg80211` 비의존 **UART BLE(`hci_uart`) / 내부 UART ESP32 브리지** + USB 3.0 금지 |
| `PE42482` 6 GHz 포트 위상 비대칭(−26.3°) · 배송 지연(R6) | V3 1회 회전 보정표에 고정 오프셋 자동 흡수; 10일 내 재고 불가 시 `HMC7992` SP4T × 3 대체(위조품 `HMC241` 주의) |
| 1기 1자리 고정 시 40명 교실 NLOS 꼬리 오차 | R3 허용 범위 내 **2위치 비동기 신뢰도 가중 로그-우도 융합** 적용 (1기 2곳 순차로 검증 뒤 필요 시 2기 동시 증설) |
| 802.11b(DSSS) 폴백으로 CSI=0 | G1 MAC 헤더 탐지는 유지하고, 방향 추정 화면에 "CSI 불가 / RSSI 폴백" 명시 |
