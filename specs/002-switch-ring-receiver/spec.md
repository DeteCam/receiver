# SPEC-002: 움직이지 않는 스위치 고리 수신기

- 상태: **명세 (검증 전)**. 실측값 없음. 2026-11-24
- 기준: [docs/AGENTS.md](https://github.com/DeteCam/docs/blob/main/AGENTS.md) (목표 G1~G3, 요구사항 R1~R9)
- 대체하는 스펙: 001-nano2-receiver (v6, 브랜치 `archive/v6-nano2`). 독립 검증에서 성능이 떨어지고 PCB 외주가 필요해 내렸다.

## 1. 무엇을, 왜

방 모서리에 둔 손바닥 크기 수신기 하나로 숨은 Wi-Fi 카메라가 보내는 신호의 방향을 잰다. 시험 중인 교실에서도 쓸 수 있도록 소리가 없고, 사람이 돌아다니지 않으며, 쇼핑몰 부품을 조립해 만든다.

## 2. 구조

- 지름 9~10 cm 원 위에 같은 막대(다이폴) 안테나 8개를 세운다.
- 기성 RF 스위치 모듈(SP4T)로 8개 가운데 하나를 골라 Intel AX210의 한 수신 단자에 잇는다.
- 다른 수신 단자에는 고정 기준 안테나 1개를 잇는다. 두 단자의 CSI 비율로 패킷마다 바뀌는 위상 오차를 지운다.
- 스위치는 Raspberry Pi Pico가 바꾸고, 호스트(라즈베리파이 5 등)가 CSI를 모아 방향을 계산한다.
- 안테나는 금속(호스트 · 배터리)에서 충분히 띄운다. 회전 수신기 계산에서는 6~10 cm가 필요했다(docs 기술검증_보고서 2부). 고리에서의 값은 계산으로 정한다.

## 3. 요구사항

| 번호 | 요구사항 | 수용 기준 | 확인 방법 |
|---|---|---|---|
| FR-1 | 두 단자 CSI 수집 | 시험 카메라의 프레임에서 두 단자 CSI가 초당 30개 이상 | V2 실측 |
| FR-2 | 위상 안정 | 안테나를 고정했을 때 두 단자 위상 차 흔들림이 1분 동안 5° 이내 | V2 실측 |
| FR-3 | 안테나 전환 | 8개를 한 바퀴 도는 시간 0.5초 이하, 전환 직후 버릴 CSI 시간을 실측으로 정함 | V3 실측 |
| FR-4 | 간섭 보정 | 보정표를 쓴 뒤 빈 방 3 m에서 방향 오차 5° 이내 | NEC2 계산 후 V3 실측 |
| FR-5 | 방향 추정 | 교실 · 반사 많은 방에서 DiffLoc 재현 장비보다 평균 방향 오차가 3° 이상 작고 95% 지점도 작음 | V4 실측 (AGENTS.md 7.3) |
| NFR-1 | 소음 | 측정 중 움직이는 부품 없음 | 구조 |
| NFR-2 | 비용 | 1기 부품 값 35만 원 이하, 시연 시스템 70만 원 미만 | 구매 기록 |
| NFR-3 | 크기 (AGENTS.md R8) | 1기 전체(안테나 · 호스트 포함, 전원 제외)가 가로 · 세로 12 cm 이하, 높이 20 cm 이하 | 조립품을 자로 잰다 |
| NFR-4 | 제작 | PCB 외주 · 납땜 없음 (SMA · 볼트 · 3D 프린트) | 조립 순서 |
| NFR-5 | 독립 동작 | 노트북 없이 배터리로 동작, 폰으로 조종 | V6 |
| NFR-6 | 무선 연결 (AGENTS.md R9) | 다른 수신기 · 허브 · 폰과는 무선으로만 연결. 연결용 무선은 AX210이 재는 채널을 방해하지 않음 | V3 · V6 |

## 4. 범위 밖

- 수신기 자체가 움직이며 재는 방식(R1, R3 위반)
- 5 GHz 전용 최적화: 2.4 GHz 카메라가 주 대상이며 5 GHz도 같은 고리로 재되 성능 목표는 G2와 같다

## 5. 확인할 것

1. 8개 안테나 간섭 크기와 보정 뒤 남는 오차 (NEC2)
2. 스위치 모듈의 2.4 GHz 손실 · 격리, 제어 전압
3. AX210 두 단자 위상 안정성 (문서로 확인 불가 → V2)
4. 호스트(라즈베리파이 5)에서 FeitCSI 동작 사례
