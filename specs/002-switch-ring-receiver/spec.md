# SPEC-002: 움직이지 않는 스위치 고리 수신기 (`SPEC-002+` 개선판)

- 상태: **명세 갱신 (V0 완료 · V1 6종 공간 검증 완료 · V2~V4 실측 전)**. 실측값 없음. 2026-11-25
- 기준: [docs/AGENTS.md](https://github.com/DeteCam/docs/blob/main/AGENTS.md) (목표 G1~G3, 요구사항 R1~R9)
- 대체하는 스펙: 001-nano2-receiver (v6, 브랜치 `archive/v6-nano2`). 독립 검증에서 성능이 떨어지고 PCB 외주가 필요해 내렸다.
- 2026-11-25 주요 구조 개선 (V0 딥 리서치 + NEC2/Sionna RT V1 검증 반영):
  - `dz=+65 mm → dz=0 mm`, `gap=60 mm`로 낮춰 R8 높이(20 cm 이하)를 만족시키고(약 16~18 cm), 기존 중심 기준 안테나를 9번째 가상 소자로 통합해 5 GHz 부엽과 꼬리 오차를 줄인다. (V1 사후 대조에서 고리 지름 `8.5 cm`도 5 GHz P95 개선 · 외경 ~9.5 cm 후보로 확인 — V3 3D 프린트 직전 0원 선택 가능.)
  - 2단 `HMC7992` SP4T × 3 대신 **단일칩 흡수형 `PE42482` SP8T 차폐 모듈**을 1순위로 채택(5.8 GHz 삽입 손실 1.1–1.4 dB, All-Off 50 Ω 종단 내장).
  - AX210 패킷당 180°($\pi$) 위상 반전 및 RX0↔RX1 스왑 대응을 위해 무PCB 기성 SMA **수동 RF 기준-누설 부호 앵커**를 설계에 포함한다(V2 3.5~5만 원 시험에서 독립 AGC 영향 최종 검증).
  - 방치된 `FeitCSI v2.0.0` 대신 **`VesperCSI` + `FeitCSI-iwlwifi` 1줄 패치(`#21`) + Linux 6.12 LTS**를 쓰고, 호스트(라즈베리파이 5) GPIO(`libgpiod`) 직접 제어로 Raspberry Pi Pico를 제거한다.
  - R9(기기 사이 무선 · 측정 무간섭) 충족을 위해 측정 버스트(1.5~2초) 중 제어 무선을 멈추는 **Burst-TDM**과 `cfg80211` 비의존 **UART BLE / 내부 UART ESP32 브리지**를 사용한다.

## 1. 무엇을, 왜

방 모서리에 둔 손바닥 크기 수신기(1기 2곳 순차 또는 2기 동시)로 숨은 2.4 GHz · 5 GHz Wi-Fi 카메라의 방향과 의심 구역을 잰다. 시험 중인 교실에서도 쓸 수 있도록 소리가 없고(R1), 사람이 돌아다니지 않으며(R3), 기성품 조립(R5)과 무선 연결(R9)로 동작한다.

## 2. 구조 (`SPEC-002+`)

- 지름 10 cm(또는 V3 선택 후보 8.5 cm) 원 위에 정품 2.4/5 GHz 듀얼밴드 SMA-Male 막대(다이폴) 안테나 8개를 세우고(`dz=0`, 하단 금속 박스 이격 `gap=60 mm`, 전체 높이 16~18 cm ≤ 20 cm), 중심에 같은 안테나 1개를 기준 안테나로 둔다.
- 단일칩 50 Ω 흡수형 RF 스위치 모듈(`PE42482` SP8T, 대체: `HMC7992` SP4T × 3)로 고리 안테나 8개 중 하나를 Intel AX210NGW의 RX1에 잇고, 중심 기준 안테나를 RX0에 잇는다.
- AX210 패킷당 $\pi$-반전을 풀기 위해 기성 SMA 분배기 · 결합기 · 고정 감쇠기로 기준 신호의 알려진 비율($|\alpha| \approx 3.5$)을 RX1에 합쳐 부호를 복원한다(V2에서 실측 검증).
- 호스트는 **라즈베리파이 5 (4–8 GB) + M.2 E-key HAT + 팬리스 알루미늄 케이스**(0 dBA, R1)를 1순위로 사용한다(대안: GMKtec NucBox G3 N100 x86, 단 팬 소음 사전 검증 필수). `VesperCSI` C 플러그인이 호스트 3.3 V GPIO(`libgpiod`)로 스위치를 직접 전환하고 전환 앞뒤 `±6~10 ms` 가드밴드와 `ftm_clock`(3.125 ns)으로 패킷을 매칭한다.
- 중심 기준 안테나(`H_ref/H_ref = 1`)를 9번째 가상 소자로 포함하고, 스윕 패킷 시간 집계에는 V1 대조군에서 딥 페이드 잡음 폭주 억제 효과가 입증된 **$|H_{\text{ref}}|^2$ 가중 켤레곱 평균** `sum(H_m · conj(H_ref)) / sum(|H_ref|^2)`을 사용한다(비가중 `mean(H_m/H_ref)` 대비 5 GHz 2자리 P95 `-13.6°` 개선, 계산값).

## 4. 범위 밖

- 수신기 자체가 움직이거나 모터로 판을 돌리는 방식(R1, R3 위반)
- 802.11b(DSSS) 폴백 프레임의 CSI 방향 추정(OFDM 부재로 물리적 불가 → G1 탐지만 수행하고 UI에 "CSI 불가 / RSSI 폴백"으로 정직하게 표시)
