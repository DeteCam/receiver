# 003 기구: 방법

## 만드는 길

```
cad/model/p2.py (치수) ─▶ parts2.py (부품 23종) ─▶ export/export2.py ─▶ print/stl/*.stl
                                                                    └▶ slicing/slice_bambu.py ─▶ print/gcode · project
cad/checks/*.py ─▶ 겹침 · 나사 · 조립 순서 · 무게와 모터 힘 · 출력 검사 · 스탠드
cad/figures/*.py ─▶ docs/images (부품 카드, 조립 그림, 영상)
```

모양은 코드(manifold3d)로 만든다. 치수 하나를 바꾸면 STL, 출력 파일, 그림, 검사가 모두 다시 나온다.

## 부품과 출력 판

| 판 | 들어 있는 것 | 시간 | 무게 |
|---|---|---|---|
| 0판 시험 조각 | 맞춤 시험 조각, 핀·기어 맞춤 3종, 마커 틀, 고리 | 1시간 31분 | 31g |
| 1판 받침 | 받침 통, 덮개, 랜선 홈 마개, 배터리 채움 조각 | 3시간 55분 | 137g |
| 2판 요크 | 요크 (회전판 + 팔 + 전선 상자) | 3시간 32분 | 125g |
| 3판 머리 | 머리 몸통, 뚜껑, 모터 자리, 부채꼴 기어 | 3시간 46분 | 107g |
| 4판 회전부 | 회전 막대 + 균형추 통 마개 (채움 100%) | 1시간 22분 | 38g |
| 5판 판 틀 | 판 틀, 누름쇠, ESP32 누름판·막음쇠 | 46분 | 18g |
| 선택: 스탠드 받이 | 스탠드 받이 (채움 100%) | 2시간 1분 | 83g |
| 선택: 큰 받침 | 큰 받침 통 / 큰 덮개 | 3시간 2분 / 2시간 21분 | 118g / 81g |

수신기 한 대(작은 받침 + 스탠드 받이): 약 17시간, 약 540g.

## 스탠드 받이

지름 140mm, 두께 12mm 원판. 가운데 육각 구멍에 1/4인치 너트를 넣고, 받침 통 밑면의 네 기둥에 M3 × 10 나사 4개로 조인다. 스탠드 꼭대기 나사에 수신기를 통째로 돌려 끼운다. 받침 통 밑면에는 이 나사가 들어갈 길잡이 구멍 4개를 미리 냈다.
