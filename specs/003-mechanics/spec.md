# 003 기구 (몸체와 움직이는 부분)

## 배경

안테나 둘레로 판을 돌리고, 그 머리를 위아래로 숙이고, 몸 전체를 좌우로 돌려야 한다. 값싼 스텝모터(28BYJ-48) 셋과 3D 프린터로 뽑은 부품으로 만든다. 시험장에서는 사람 머리 위 높이(2.0~2.4m)에 올려야 한다.

## 요구사항

| 번호 | 내용 |
|---|---|
| FR-1 | 관절 셋: 받침 회전(좌우, 기어 4:1), 끄덕임(위아래 -5°~85°, 기어 11.2:1), 판 회전(한 바퀴, 모터 직결) |
| FR-2 | 알루미늄 판 100 × 150 × 1mm 를 구멍 없이 판 틀의 홈에 끼워 잡는다. 반대쪽에 100원 동전 12개로 무게를 맞춘다 |
| FR-3 | 모든 부품은 나사로 고정한다 (테이프·접착제 없음). 납땜도 없다 |
| FR-4 | 라즈베리파이 3B+, 드라이버 보드 3장, ESP32, 동글 2개, 전원 버튼이 머리 안에 들어간다 |
| FR-5 | 보조배터리는 받침 안에 넣는다. 작은 받침(지름 140mm, 배터리 106 × 71 × 22mm 까지)과 큰 받침(지름 190mm, 152 × 76 × 22mm 까지) |
| FR-6 | 받침 밑에 **스탠드 받이**를 달아 조명 스탠드의 1/4인치 나사에 올린다. 떼면 책상 위에 그대로 놓인다 |
| FR-7 | 머리 등판에 AR 마커(34mm 두 개)를 붙여 폰이 수신기의 자리와 방향을 안다 |
| NFR-1 | Bambu X1 Carbon(256mm 판) 에서 받침 없이 뽑힌다. 부품을 미리 재지 않아도 맞는 것을 골라 쓰게 맞춤 조각을 같이 뽑는다 |
| NFR-2 | 모터 힘의 90% 안에서 움직인다. 전원이 꺼져도 머리가 떨어지지 않는다 |
| NFR-3 | 책상 위에서 스스로 넘어지지 않는다. 스탠드 위에서는 모래주머니(3kg 이상)를 쓴다 |

## 수용 기준

계산 검사 (`cad/checks`, 모두 문제 0개):

| 검사 | 결과 |
|---|---|
| 나사 59개 가는 길과 드라이버 자리 | 확인할 것 0개 |
| 조립 47단계 가는 길 겹침 | 0 |
| 움직이는 범위 전체에서 부품 사이 틈 | 가장 좁은 곳 0.5mm (판 회전부와 머리) |
| 끄덕임 모터 | 기울임 자세에서 모터 힘의 60%, 가장 깊이 숙였을 때 87% |
| 받침 회전 마찰 | 비비탄을 넣으면 모터 힘의 6% |
| 출력 판 11장 | 모두 문제 0개 |
| 스탠드 받이 | 나사 4개 여유 259배, 모터가 돌 때 풀리지 않을 여유 11.5배 |
| 스탠드 위 2.4m | 모래주머니 없이는 꼭대기를 2.1N(약 210g)으로 밀면 넘어진다. 3kg 을 올리면 4.9N |

실물: 출력 → 맞춤 조각 고르기 → 조립 → 관절 셋이 끝에서 끝까지 걸림 없이 움직인다.

## 범위 밖

- 방수, 낙하 충격. 실외에서 쓰는 것.

## 확인할 것

- 출력 오차. 구멍·핀이 설계보다 얼마나 작게·크게 나오는지 0판(시험 조각)으로 먼저 본다.
- 스탠드를 끝까지 폈을 때 흔들림이 측정에 주는 영향.
