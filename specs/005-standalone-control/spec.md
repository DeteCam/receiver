# 005 혼자 동작과 조종

## 배경

수신기는 노트북 없이 써야 한다. 전원을 넣으면 스스로 켜지고, 폰이 수신기의 Wi-Fi 에 붙어 모든 동작을 시킨다. 노트북과 랜선은 개발할 때만 쓴다.

## 요구사항

| 번호 | 내용 |
|---|---|
| FR-1 | 전원을 넣으면 60초 안에 수신기 Wi-Fi(`DeteCam-RX`)가 뜨고 `http://192.168.4.1` 이 열린다 |
| FR-2 | 주소(API)로 상태 보기, 탐지, 판별, 측정, 시험장 진행, 멈춤, 정비(원점 잡기)를 시킨다. 목록은 [주소 계약](https://github.com/DeteCam/app/blob/main/docs/주소%20계약.md) |
| FR-3 | 앱이 없어도 폰 브라우저로 같은 일을 할 수 있는 화면 한 장을 준다 |
| FR-4 | 전원 버튼: 짧게 누르면 한 번 재고, 2초 누르면 안전하게 꺼진다 |
| FR-5 | 멈춤을 받으면 1초 안에 모터가 선다 |
| FR-6 | 전압이 모자라거나 뜨거우면 상태에 경고를 싣는다 |
| NFR-1 | 폰과 끊겨도 하던 측정은 끝까지 가고, 다시 붙으면 결과를 준다 |

## 수용 기준

- 노트북 없이 보조배터리만으로 켜서 측정 한 번을 끝낸다.
- `firmware/tests/test_control.py` 통과. 멈춤 10번 가운데 10번이 1초 안.

## 범위 밖

- 인터넷 연결, 계정, 원격 조종. 펌웨어 무선 갱신.
