# 006 패널 수신기: 방법

## 신호의 길

```
카메라 ─전파─▶ 패치 16개 ─스위치(16 가운데 1)──────────────────┐
              기준 안테나 ─스위치 A ─ 선 넷(0·90·180·270도) ─ 스위치 B ─▶ 합침기 ─▶ ESP32-C5 (CSI 의 세기)
ESP32-C5 ─ USB 또는 ESP-NOW ─▶ 허브(파이) ─▶ 자리 확률 ─▶ 폰
```

한 번 재기 = 안테나 16 × 위상 단계 4 = 패킷 64개. 안테나마다 `(I0 - I180) - j(I90 - I270) = 4 r* h` 로 '기준의 켤레 × 안테나'를 얻는다. 기준이 같으므로 안테나 사이의 위상 차이가 남는다.

## 부품

| 것 | 고른 것 | 까닭 |
|---|---|---|
| 안테나 판 | CoreHW CHW1010-ANT2 (150 × 150, 패치 16 + 16갈래 스위치) | 블루투스 방향 찾기용으로 파는 것. RF 단자가 하나라 수신 길 하나에 맞는다 |
| 받는 칩 | XIAO ESP32-C5 | ACK 의 CSI 를 내는 설정이 있다. 안테나 16개까지 고르는 신호를 낸다 |
| 위상 4단 | SP4T 스위치 둘 + 길이가 다른 선 넷 | 모듈로 살 수 있다. 실제 위상은 장치가 잰다 |
| 허브 | 라즈베리파이 3B+, 동글 둘, 보조배터리 | 돌판 때의 탐지·판별·폰 화면을 그대로 쓴다 |

## 거는 곳

패널 둘을 마주 보는 두 옆벽의 2 m 높이에. 못 걸면 하나는 칠판 윗변에. 강의실은 셋. 근거는 설계 검토 5절과 6절.

## 순서

1. 0단계 실험 (책상 위에서, 통 없이)
2. 패널 하나: 출력, 조립, 위상 단계 재기, 방향 오차 재기
3. 패널 둘과 허브: 서로 재서 방향 맞추기, 자리 내기, 교실에서 재기
4. 폰 화면에 자리 후보 셋 보이기 (app 저장소)
