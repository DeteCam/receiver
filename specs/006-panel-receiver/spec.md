# 006 패널 수신기 (모터 없이 방향 재기)

## 배경

판을 돌려 방향을 재는 수신기(001, 003)는 시험장에서 쓰기 어렵다. 2.4 m 스탠드를 세울 수 없고, 감독관이 수신기를 옮기는 곳은 둘 이하여야 하고, 모터 소리가 나면 안 된다. 시험지를 찍는 카메라는 사진을 가끔 한 장씩만 보낼 수 있는데, 돌판은 한 곳에서 110초 동안 이어지는 신호가 있어야 방향을 잰다.

손이 닿는 높이 두 곳에서 돌판은 책상 위 카메라의 자리를 21~55% 만 맞혔다 (교실 40석, 전파 경로 계산). 원인은 방향 오차다. 직접 보이는 카메라도 9도쯤 틀린다. 그래서 받는 쪽을 안테나 배열(패널)로 바꾼다. 까닭과 견준 방법은 [설계 검토](../../docs/설계%20검토.md)에 있다.

## 요구사항

| 번호 | 내용 |
|---|---|
| FR-1 | 패널 하나가 Wi-Fi 기기의 방향(방위각과 높이각)을 한 번에 잰다. 패치 안테나 16개(4 × 4)를 전자 스위치로 고른다 |
| FR-2 | 수신 길이 하나인 ESP32-C5 로 잰다. 기준 안테나와 합친 세기를 기준 길의 위상 네 단계에서 재서 위상을 되찾는다 (패킷 64개) |
| FR-3 | 패널 둘 이상이 잰 것과, 같은 기기가 여러 번 보낸 것을 곱해 자리 확률을 낸다. 후보 셋을 낸다 |
| FR-4 | 패널은 걸어 둔 채 쓴다: 칠판에 자석, 유리에 흡착 걸이, 창턱·교탁·사물함 위에 받침 발, 삼각대 |
| FR-5 | 패널의 자리와 방향은 앞덮개의 AR 마커로 폰이 안다. 방향은 패널끼리 서로를 재서 맞춘다 |
| FR-6 | 허브(라즈베리파이 + 동글 둘 + 배터리)가 탐지(004)를 하고 패널이 잰 것을 모아 폰(005)에 보여 준다 |
| FR-7 | 기준 길의 위상 단계는 장치가 스스로 잰다 (선 길이의 오차를 받아 준다) |
| NFR-1 | 움직이는 부품이 없다 (소리가 나지 않는다) |
| NFR-2 | 한 번 재는 시간 0.5초 이하. 0.5초만 보내는 기기도 잰다 |
| NFR-3 | 방향 오차(가운데값) 직접 보일 때 4도 이하 |
| NFR-4 | Bambu X1 Carbon 에서 받침 없이 뽑힌다. 안테나 판과 RF 모듈은 사 온다 |
| FR-8 | 같은 패널 하나로 숙소 방에 숨긴 기기의 자리(벽·천장·가구 겉면의 점)를 낸다. 여러 곳에서 잰 것을 겹치고, 기기를 등진 쪽에서 잰 것은 버린다 |
| NFR-5 | 부품은 관문마다 나눠 산다. 앞 관문을 통과해야 다음 것을 산다 |

## 수용 기준

계산 (모두 통과):

| 기준 | 결과 |
|---|---|
| 방향 오차, 직접 보일 때 (`rt_study.py bearing`) | 가운데값 3.6도 |
| 교실 40석, 패널 둘, 한 번: 책상 위 / 가슴 / 안경 | 70 / 56 / 70% (옆자리까지 90 / 81 / 93%) |
| 같은 조건, 여덟 번 모아서 | 84 / 87 / 90% (옆자리까지 97 / 97 / 100%) |
| 강의실 72석, 패널 셋, 여덟 번 | 89 / 94 / 99% |
| 0.15초, 잡음 열 배 | 차이 없음 |
| 세기 네 번에서 위상 되찾기 (`firmware/tests/test_panel.py`) | 오차 0.3% (잡음 없이), 위상 단계 스스로 재기 3.5도, 자리 30 / 30 |
| 세기 재기에 흔들림을 넣어도 (이득 2 dB, 위상 단계 20도, 4비트, 잡음 10 dB) (`sim/rt/run_pre.sh`) | 옆자리까지 4점 안에서 버틴다. 정확히는 7점까지 떨어진다 |
| 숙소 방, 패널 하나, 가운데에서 다섯 쪽 / 네 자리 (`sim/rt/room_study.py`) | 가운데값 0.26 m / 0.20 m, 50 cm 안 78% / 89% |
| 기계 검사 (`cad/checks/panel_check.py`) | 겹침 0, 넘어지는 각 19도 이상, 자석 여유 1.9~2.8배 |
| 출력 다섯 판 (`print/print_check.json`) | 문제 0 |

실물 (관문. 앞의 것이 되어야 다음 것을 사고 만든다. 방법은 [사전 검증](../../docs/사전%20검증.md)):

| 관문 | 사는 것 | 기준 |
|---|---|---|
| 1 | ESP32-C5 2 (3.0만 원) | 다른 기기의 ACK 의 80% 이상에서 CSI 가 나온다. 이득 값을 되돌린 뒤 이어진 패킷의 진폭 차가 0.5 dB 안 |
| 2 | 합침기, 선, 변환 단자 (3.6만 원) | 안테나 둘과 위상 네 단계(선을 손으로 바꿔)로 위상 차이가 나온다. 오차 15도 안, 되풀이 10도 안 |
| 3 | RF 스위치 2 (5.1만 원) | 스위치로 바꿔도 손으로 잰 것과 10도 안. 패킷 64개에 0.5초 안 |
| 4 | 안테나 보드 1 과 첫 패널의 재료 (15.4만 원) | 아는 자리의 송신기 방향이 직접 보일 때 6도 안. 교실에서 패널 하나로 옆자리까지 70% 이상. 숙소 방에서 가운데값 0.5 m 이하 |
| 5 | 둘째 패널, 동글, 나머지 (26.5만 원) | [데모 환경](../../docs/데모%20환경.md)의 강의실 기준 |

## 범위 밖

- 5 GHz 로만 보내는 카메라의 방향 (보드가 2.4 GHz 용이다). 탐지는 한다
- 블루투스로만 보내는 기기, LTE 로 직접 보내는 카메라
- 배운 모델(AI)로 자리 내기. 계산으로는 이득이 있지만 그 교실의 모형이 필요하다. 실물을 본 뒤에 정한다
- 돌판 수신기 (001, 003). 태그 `plate-v2` 에 둔다. 관문 2 가 끝내 안 되면 돌아간다
